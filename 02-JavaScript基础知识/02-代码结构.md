# 02 代码结构

> 原文：`zh.javascript.info/1-js/02-first-steps/02-structure/article.md`

## 知识点

### 1. 语句（statement）
- 语句是执行行为的语法结构，用分号 `;` 分隔。
- 通常一条语句独占一行以提高可读性。

### 2. 分号与自动分号插入（ASI）
- 有换行时，**大多数情况**可以省略分号，引擎会把换行当作"隐式分号"（Automatic Semicolon Insertion）。
- 但换行 **不总是** 分号。例如行尾是 `+`，表达式未完成，不会插入分号：

```js
alert(3 +
1
+ 2); // 6
```

- **危险场景**：下一行以 `[`、`(` 等开头时，引擎不会插入分号，两行会被合并成一条语句：

```js
alert("Hello")
[1, 2].forEach(alert);
// 被理解为：alert("Hello")[1, 2].forEach(alert);  → 报错
```

- **结论**：即使有换行，也建议始终写分号，这是社区广泛采用的规则，对新手尤其重要。

### 3. 注释
- 单行注释：`// ...`，可以独占一行或跟在语句后面。
- 多行注释：`/* ... */`。
- 注释被引擎忽略，可用于临时禁用代码。
- **不支持嵌套**：`/* /* ... */ */` 会报错。
- 编辑器快捷键：`Cmd+/` 单行注释，`Cmd+Option+/` 块注释（Mac）。
- 注释不影响生产体积：构建工具（minifier）部署前会移除注释。

## 与 Java 对比
- Java 分号是强制的；JS 语法上可选（ASI），但**实践中当作强制来写**，避免 ASI 的坑。
- 注释语法与 Java 完全一致（`//`、`/* */`），同样不允许嵌套块注释。

## 一句话总结
语句用分号分隔，别依赖 ASI，始终写分号；注释与 Java 相同，不能嵌套。

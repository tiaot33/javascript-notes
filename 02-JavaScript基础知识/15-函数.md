# 15 函数

> 原文：`zh.javascript.info/1-js/02-first-steps/15-function-basics/article.md`

## 知识点

### 1. 函数声明
- 函数是程序的主要"构建模块"，让一段代码可以被多次调用，避免重复。
- `alert`、`prompt`、`confirm` 是内建函数，也可以自己创建。

```js
function showMessage() {
  alert( 'Hello everyone!' );
}

showMessage();
showMessage(); // 显示两次
```

- 结构：`function` 关键字 → 函数名 → 括号内的参数列表（逗号分隔） → 花括号内的函数体。

```js
function name(parameter1, parameter2, ... parameterN) {
  ...body...
}
```

### 2. 局部变量
- 函数内声明的变量只在函数内可见：

```js
function showMessage() {
  let message = "Hello, I'm JavaScript!"; // 局部变量
  alert( message );
}

showMessage(); // Hello, I'm JavaScript!
alert( message ); // 错误！
```

### 3. 外部变量
- 函数可以访问并**修改**外部变量：

```js
let userName = 'John';

function showMessage() {
  userName = "Bob"; // 改变外部变量
  let message = 'Hello, ' + userName;
  alert(message);
}

alert( userName ); // John
showMessage();
alert( userName ); // Bob，被函数修改了
```

- 只有没有同名局部变量时才会用外部变量。函数内声明同名变量会**遮蔽**外部变量：

```js
let userName = 'John';

function showMessage() {
  let userName = "Bob"; // 局部变量，遮蔽外部
  alert( 'Hello, ' + userName ); // Bob
}

showMessage();
alert( userName ); // John，未被改变
```

- **全局变量**：任何函数之外声明的变量，在任意函数中可见（除非被遮蔽）。现代代码尽量减少全局变量，只用于存储项目级别的数据。

### 4. 参数
- 通过参数向函数传递任意数据，调用时值被**复制**到局部变量：

```js
function showMessage(from, text) {
  alert(from + ': ' + text);
}

showMessage('Ann', 'Hello!');      // Ann: Hello!
showMessage('Ann', "What's up?"); // Ann: What's up?
```

- 函数修改参数不影响外部变量，因为改的是副本：

```js
function showMessage(from, text) {
  from = '*' + from + '*';
  alert( from + ': ' + text );
}

let from = "Ann";
showMessage(from, "Hello"); // *Ann*: Hello
alert( from ); // Ann，没变
```

- 术语：
  - **parameter（形参）**：函数声明时括号内列出的变量。
  - **argument（实参）**：调用时实际传入的值。

### 5. 默认值
- 调用时未提供的参数值为 `undefined`，**不报错**：`showMessage("Ann")` 输出 `"Ann: undefined"`。
- 用 `=` 在声明中指定默认值（ES6）：

```js
function showMessage(from, text = "no text given") {
  alert( from + ": " + text );
}

showMessage("Ann"); // Ann: no text given
```

- 默认值可以是任意表达式，**只在缺少该参数时才求值**，每次调用都重新计算：

```js
function showMessage(from, text = anotherFunction()) {
  // anotherFunction() 仅在没传 text 时执行
}
```

- 老代码中的默认参数写法（ES6 之前没有默认参数语法）：

```js
// 显式检查 undefined
if (text === undefined) { text = 'no text given'; }

// 用 ||（注意：text 为 "" 或 0 时也会被替换）
text = text || 'no text given';
```

**后备的默认参数**：也可以在函数执行期间设置默认值，而不是在声明时：

```js
function showMessage(text) {
  if (text === undefined) {
    text = 'empty message';
  }
  alert(text);
}
```

- 现代写法用 `??`，在 `0` 等假值应被视为正常值时更合适：

```js
function showCount(count) {
  alert(count ?? "unknown");
}

showCount(0);    // 0
showCount(null); // unknown
showCount();     // unknown
```

### 6. 返回值
- `return` 把值返回给调用方；执行到 `return` 函数立即停止：

```js
function sum(a, b) {
  return a + b;
}

let result = sum(1, 2);
alert( result ); // 3
```

- 一个函数可以有多个 `return`：

```js
function checkAge(age) {
  if (age >= 18) {
    return true;
  } else {
    return confirm('Got a permission from the parents?');
  }
}
```

- 不带值的 `return;` 用于立即退出函数：

```js
function showMovie(age) {
  if ( !checkAge(age) ) {
    return;
  }
  alert( "Showing you the movie" );
}
```

- **没有 `return` 或空 `return` 的函数返回 `undefined`**：

```js
function doNothing() { /* 没有代码 */ }
alert( doNothing() === undefined ); // true
```

- **坑：不要在 `return` 与返回值之间换行**。JS 会在 `return` 后自动插入分号，下面的代码实际返回 `undefined`：

```js
return
 (some + long + expression + or + whatever * f(a) + f(b))
// 等价于 return; (...)
```

正确写法是表达式与 `return` 同行开始，或至少左括号同行：

```js
return (
  some + long + expression
  + or +
  whatever * f(a) + f(b)
  )
```

### 7. 函数命名
- 函数是行为，名字通常是**动词**，简短且准确描述作用。
- 常见动词前缀（团队内需达成一致）：

| 前缀 | 含义 | 示例 |
|---|---|---|
| `show…` | 显示某些内容 | `showMessage(..)` |
| `get…` | 返回一个值 | `getAge(..)` |
| `calc…` | 计算某些内容 | `calcSum(..)` |
| `create…` | 创建某些内容 | `createForm(..)` |
| `check…` | 检查并返回布尔值 | `checkPermission(..)` |

- **一个函数，一个行为**：函数只做名字所说的事。两个独立行为应是两个函数（即使总是一起调用，可再建第三个函数调用这两个）。反例：
  - `getAge` 顺便 `alert` 显示年龄——不该显示。
  - `createForm` 顺便把表单加到文档——只应创建并返回。
  - `checkPermission` 顺便显示 "access granted/denied"——只应检查并返回结果。
- 极短的函数名（jQuery 的 `$`、Lodash 的 `_`）是例外，一般函数名要简明且有描述性。

### 8. 函数 == 注释
- 函数应简短且只做一件事；复杂就拆成几个小函数。
- 单独的函数更容易测试和调试，**其存在本身就是一个好注释**（自描述代码）。
- 对比两种 `showPrimes(n)`：用标签 `continue nextPrime` 的版本，与拆出 `isPrime(n)` 的版本，后者通过函数名就能看懂行为：

```js
function showPrimes(n) {
  for (let i = 2; i < n; i++) {
    if (!isPrime(i)) continue;
    alert(i);
  }
}

function isPrime(n) {
  for (let i = 2; i < n; i++) {
    if ( n % i == 0) return false;
  }
  return true;
}
```

- 即使不打算复用，也可以为了结构清晰、可读性而创建函数。

### 9. 原文总结要点
- 传给函数的值被复制到局部变量。
- 函数能访问外部变量，但外部看不到函数内的局部变量。
- 没有返回值就返回 `undefined`。
- 优先使用局部变量和参数而非外部变量；"接收参数、使用参数、返回结果"的函数比"修改外部变量作为副作用"的函数更易理解。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| 方法必须属于类，需声明返回类型和参数类型 | 函数独立存在，`function name(a, b) {}`，无类型声明 | 顶层函数直接写，不需要类包裹 |
| 参数数量必须匹配，否则编译错误 | 少传 → `undefined`，多传 → 忽略，**都不报错** | 没有编译期保护，靠默认值和文档 |
| 无默认参数，靠方法重载模拟 | `function f(a, b = 1)` 直接写默认值 | ES6 新语法；JS 也没有重载，同名函数后者覆盖前者 |
| `void` 方法无返回值 | 没有 `return` 就返回 `undefined` | 所有函数都"有返回值" |
| 基本类型按值传递，对象传引用副本 | 相同 | 原始类型改副本不影响外部；对象参数后续章节讲，行为与 Java 一致 |
| 方法内不能直接访问方法外的局部变量（只能访问字段） | 函数可以读写外层作用域的任何变量 | 闭包基础，后续深入；同名局部变量遮蔽外部与 Java 相同 |
| `return` 换行后写表达式没问题（编译器处理） | `return` 后换行会自动插分号，返回 `undefined` | JS 特有的坑，务必同行 |
| 命名规范：动词开头，`getX`/`setX`/`isX` | 相同风格，`get…`/`show…`/`check…` | 一致 |
| 单一职责原则 | 相同 | 一致 |

**实践建议**：
- 默认值用 `= ` 语法，不再用 `text = text || 'x'`（会误替换 `0`/`""`）。
- 需要跨多行的 `return` 表达式，左括号与 `return` 同行。
- 调用时参数个数不匹配不报错，用 TypeScript 或 JSDoc 可弥补。

## 一句话总结
`function name(params) { body }` 声明函数；参数按值复制、可有默认值、少传为 `undefined`；函数能读写外部变量但局部变量优先并遮蔽外部；没有 `return` 返回 `undefined`，且 `return` 后不能换行；命名用动词前缀，一个函数只做一件事，好的函数名就是注释。

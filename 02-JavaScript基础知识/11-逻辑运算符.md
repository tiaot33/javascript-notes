# 11 逻辑运算符

> 原文：`zh.javascript.info/1-js/02-first-steps/11-logical-operators/article.md`

## 知识点

### 0. 概述
- JS 有四个逻辑运算符：`||`（或）、`&&`（与）、`!`（非）、`??`（空值合并，下一篇讲）。
- 虽然叫"逻辑"运算符，但**可以应用于任意类型的值，结果也可以是任意类型**，不限于布尔值。这是与传统语言最大的差别。

### 1. `||`（或）
- 操作数是布尔值时与传统一致，只有两个都为 `false` 结果才是 `false`：

```js
alert( true || true );   // true
alert( false || true );  // true
alert( true || false );  // true
alert( false || false ); // false
```

- 操作数不是布尔值时，先转成布尔值参与运算：`if (1 || 0)` 相当于 `if (true || false)`。
- 最常见用法：在 `if` 中测试是否有**任一**条件成立，可以串多个：

```js
if (hour < 10 || hour > 18 || isWeekend) {
  alert( 'The office is closed.' );
}
```

### 2. 或运算寻找第一个真值
`result = value1 || value2 || value3;` 的算法：
- 从左到右依次计算操作数。
- 每个操作数转成布尔值，若为 `true` 则**停止计算，返回该操作数的原始值**（不做布尔转换）。
- 所有操作数都是假值时，返回**最后一个操作数**。

```js
alert( 1 || 0 );                 // 1
alert( null || 1 );              // 1
alert( null || 0 || 1 );         // 1（第一个真值）
alert( undefined || null || 0 ); // 0（都是假值，返回最后一个）
```

由此带来两个用法：

**(1) 获取列表中第一个真值 / 提供默认值**

```js
let firstName = "";
let lastName = "";
let nickName = "SuperCoder";

alert( firstName || lastName || nickName || "Anonymous" ); // SuperCoder
```

**(2) 短路求值（short-circuit evaluation）**
- 遇到第一个真值就立刻返回，后面的操作数不再计算。当操作数是有副作用的表达式（赋值、函数调用）时很重要：

```js
true || alert("not printed");  // 不执行 alert
false || alert("printed");     // 执行
```

- 有人利用这个特性"只在左侧为假时才执行右侧"。

### 3. `&&`（与）
- 布尔值时与传统一致，两个都为 `true` 才返回 `true`：

```js
alert( true && true );   // true
alert( false && true );  // false
alert( true && false );  // false
alert( false && false ); // false
```

```js
if (hour == 12 && minute == 30) {
  alert( 'Time is 12:30' );
}
```

- 操作数同样可以是任意类型：`if (1 && 0)` 相当于 `true && false`。

### 4. 与运算寻找第一个假值
`result = value1 && value2 && value3;` 的算法：
- 从左到右依次计算操作数。
- 每个操作数转成布尔值，若为 `false` 则**停止计算，返回该操作数的原始值**。
- 所有操作数都是真值时，返回**最后一个操作数**。

与 `||` 的规则对称：`&&` 返回第一个假值，`||` 返回第一个真值。

```js
// 第一个是真值 → 返回第二个
alert( 1 && 0 ); // 0
alert( 1 && 5 ); // 5

// 第一个是假值 → 直接返回它，第二个被忽略
alert( null && 5 );             // null
alert( 0 && "no matter what" ); // 0

alert( 1 && 2 && null && 3 ); // null（第一个假值）
alert( 1 && 2 && 3 );         // 3（都是真值，返回最后一个）
```

- **`&&` 优先级高于 `||`**：`a && b || c && d` 等价于 `(a && b) || (c && d)`。

**不要用 `||` 或 `&&` 取代 `if`**：

```js
(x > 0) && alert( 'Greater than zero!' ); // 能跑，但不推荐

if (x > 0) alert( 'Greater than zero!' ); // 更清晰
```

原则：想要 `if` 就用 `if`，想要逻辑与就用 `&&`。

### 5. `!`（非）
- 语法 `result = !value;`，两步：先把操作数转成布尔值，再取反。

```js
alert( !true ); // false
alert( !0 );    // true
```

- **`!!` 用于把任意值转成布尔值**（第一个 `!` 转布尔并取反，第二个再取反）：

```js
alert( !!"non-empty string" ); // true
alert( !!null );               // false
```

- 等价但更冗长的写法：`Boolean(value)`。
- `!` 优先级在所有逻辑运算符中**最高**，总是先于 `&&` 和 `||` 执行。

### 6. 优先级小结
`!` > `&&` > `||`（`??` 与 `||` 同级，下一篇讲）。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `\|\|`、`&&`、`!` 只接受 `boolean`，结果必是 `boolean` | 接受任意类型，**返回操作数的原始值** | 这是 JS 逻辑运算符的核心差别：`null \|\| "x"` 返回 `"x"`，不是 `true` |
| `\|\|`、`&&` 同样短路 | 相同 | 短路语义一致 |
| 还有非短路的 `\|`、`&` 逻辑运算 | `\|`、`&` 只是位运算 | JS 中 `a \| b` 会把两边转成 32 位整数，别拿来当逻辑运算 |
| 默认值写法：`x != null ? x : "default"` 或 `Optional.orElse` | `x \|\| "default"` | 简洁，但注意 `0`、`""`、`false` 也会被替换掉，需要区分时用 `??`（下一篇） |
| 无对应写法 | `!!x` 转布尔 | 惯用写法，等价 `Boolean(x)` |
| 空判断 `if (str != null && !str.isEmpty())` | `if (str)` | 一步到位，但 `"0"` 是真值、`0` 是假值，注意语义 |
| 安全调用需要显式判空：`if (user != null && user.name != null)` | `user && user.name` | 后续会学更简洁的可选链 `user?.name` |
| 优先级 `!` > `&&` > `\|\|` | 相同 | 完全一致 |

**实践建议**：
- 记住 `||` 返回第一个真值、`&&` 返回第一个假值、都不是返回布尔——需要确定的布尔值时用 `!!` 或 `Boolean()`。
- 用 `||` 设默认值时想清楚 `0`/`""`/`false` 是否合法值，是的话改用 `??`。
- 不要用 `&&`/`||` 代替 `if` 执行副作用。

## 一句话总结
`||` 返回第一个真值、`&&` 返回第一个假值（没找到则返回最后一个操作数），两者都短路且返回原始值而非布尔；`!` 转布尔取反，`!!x` 是把任意值转布尔的惯用法；优先级 `!` > `&&` > `||`。

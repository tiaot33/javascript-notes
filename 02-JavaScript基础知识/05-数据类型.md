# 05 数据类型

> 原文：`zh.javascript.info/1-js/02-first-steps/05-types/article.md`

## 知识点

### 0. 动态类型
- JS 是**动态类型**语言：变量不绑定类型，前一刻是字符串，下一刻可以存数字，不报错。

```js
let message = "hello";
message = 123456; // 没有错误
```

### 1. 八种基本数据类型总览
**七种原始类型（primitive）**：`number`、`bigint`、`string`、`boolean`、`null`、`undefined`、`symbol`
**一种引用类型**：`object`

### 2. `number`
- 整数和浮点数都是 `number`，没有 int/long/double 之分。
- 三个特殊数值：`Infinity`、`-Infinity`、`NaN`。
  - `1 / 0` → `Infinity`，不会抛异常。
  - `"not a number" / 2` → `NaN`，代表计算错误。
  - **`NaN` 是粘性的**：任何含 `NaN` 的运算结果都是 `NaN`（唯一例外：`NaN ** 0 === 1`）。
- 数学运算是"安全的"：除以 0、对非数字字符串做运算都不会让脚本崩溃，最坏得到 `NaN`。

### 3. `bigint`
- `number` 只能安全表示 `±(2^53 - 1)`（即 `±9007199254740991`）范围内的整数，超出后精度丢失：

```js
9007199254740991 + 1 // 9007199254740992
9007199254740991 + 2 // 9007199254740992（相同！）
```

- `bigint` 用于任意长度整数，字面量在末尾加 `n`：`const big = 1234567890123456789012345678901234567890n;`
- 使用场景少（密码学、微秒级时间戳），IE 不支持。

### 4. `string`
- 三种引号：双引号 `"Hello"`、单引号 `'Hello'`、反引号 `` `Hello` ``。
- 双引号和单引号**没有区别**。
- **反引号是模板字符串**（ES6），支持用 `${…}` 嵌入变量或任意表达式：

```js
let name = "John";
alert( `Hello, ${name}!` );        // Hello, John!
alert( `the result is ${1 + 2}` ); // the result is 3
alert( "the result is ${1 + 2}" ); // 原样输出，双引号不解析 ${}
```

- **没有 `char` 类型**，单个字符也是长度为 1 的字符串。

### 5. `boolean`
- 只有 `true` 和 `false`，比较运算的结果就是布尔值：`let isGreater = 4 > 1;`

### 6. `null`
- 自成一个类型，只包含 `null` 一个值。
- **不是**"指向不存在对象的引用"或"空指针"，只是一个代表"无"、"空"、"值未知"的特殊值。

### 7. `undefined`
- 自成一个类型，含义是"未被赋值"。
- 变量已声明但未赋值，其值就是 `undefined`。
- 可以手动赋 `undefined`，但**不建议**。约定：用 `null` 表示"空 / 未知"，`undefined` 留给"未初始化"的默认状态。

### 8. `object` 与 `symbol`
- `object` 是唯一的非原始类型，用于存储数据集合和复杂实体，后续单独章节详讲。
- `symbol` 用于创建对象的唯一标识符，学完对象后再学。

### 9. `typeof` 运算符
- 以**字符串**形式返回类型名，`typeof x` 和 `typeof(x)` 等价（括号只是分组，`typeof` 是运算符不是函数）。

```js
typeof undefined     // "undefined"
typeof 0             // "number"
typeof 10n           // "bigint"
typeof true          // "boolean"
typeof "foo"         // "string"
typeof Symbol("id")  // "symbol"
typeof Math          // "object"
typeof null          // "object"    ← 官方承认的历史 bug，null 不是 object
typeof alert         // "function"  ← 函数本质是 object，但 typeof 特殊对待，实践中很方便
```

**两个必须记住的特例**：
- `typeof null === "object"`：语言早期的错误，为兼容性保留。
- `typeof function === "function"`：没有独立的 function 类型，函数属于 `object`，但 `typeof` 返回 `"function"`。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `byte/short/int/long/float/double` 六种数值类型 | 只有 `number`（IEEE 754 双精度） | JS 整数本质是 double，安全整数范围只有 2^53；大整数用 `bigint` |
| `1 / 0` 抛 `ArithmeticException` | `Infinity` | JS 数学运算不抛异常 |
| `Integer.MAX_VALUE + 1` 溢出回绕 | 精度丢失但不回绕 | 超出 2^53 后奇数无法精确表示 |
| `BigInteger` 类 | `bigint` 原始类型，字面量加 `n` | 不能与 `number` 直接混合运算 |
| `char` 与 `String` 分开 | 只有 `string` | `"a"` 就是长度 1 的字符串 |
| `String.format` / `+` 拼接 | 模板字符串 `` `${x}` `` | ES6 新语法，优先使用 |
| `null` 一种"空" | `null` 和 `undefined` 两种"空" | `undefined` = 未初始化，`null` = 人为设为空 |
| 静态类型，编译期检查 | 动态类型，运行时用 `typeof` 检查 | 同一变量可存不同类型的值 |
| `instanceof` / `getClass()` | `typeof`（原始类型）、`instanceof`（对象，后续讲） | `typeof` 对 `null` 和函数有特例 |

**实践建议**：
- 判断是否为 `null` 不能用 `typeof`，直接用 `x === null`。
- 判断"空值"时通常同时考虑 `null` 和 `undefined`（后续会学 `==` 与 `??` 处理这两者）。

## 一句话总结
JS 有 7 种原始类型 + `object`；数值只有 `number`（含 `NaN`/`Infinity`）和 `bigint`；字符串优先用模板字符串；`null` 与 `undefined` 是两个不同的"空"；`typeof` 检查类型，记住 `null` 和函数两个特例。

# 16 函数表达式

> 原文：`zh.javascript.info/1-js/02-first-steps/16-function-expressions/article.md`

## 知识点

### 1. 函数表达式
- 在 JS 中，函数不是"神奇的语言结构"，而是一种**特殊的值**。
- 之前用的语法叫**函数声明**：

```js
function sayHi() {
  alert( "Hello" );
}
```

- 另一种创建函数的语法叫**函数表达式**，允许在任何表达式中间创建函数：

```js
let sayHi = function() {
  alert( "Hello" );
};
```

- 函数创建发生在赋值表达式（`=` 右侧）的上下文中，所以是"表达式"。`function` 后面**没有函数名**（可省略）。
- 两种写法含义一样："创建一个函数并放入变量 `sayHi`"。
- 更高阶的场景：创建后立即调用，或安排稍后执行，不存到任何地方，保持匿名。

### 2. 函数是一个值
- 无论如何创建，函数都是一个值，可以像其他值一样使用。
- 用 `alert` 显示函数变量，会显示函数源码——注意 **`sayHi` 后没有括号，不会调用**：

```js
function sayHi() {
  alert( "Hello" );
}

alert( sayHi ); // 显示函数代码，不执行
```

- 可以把函数复制到其他变量：

```js
function sayHi() {   // (1) 创建
  alert( "Hello" );
}

let func = sayHi;    // (2) 复制（没有括号！）

func();  // Hello    // (3) 通过副本调用
sayHi(); // Hello    //     原来的也能调用
```

- `(2)` 若写成 `func = sayHi()`，则是把 `sayHi()` 的**调用结果**（`undefined`）赋给 `func`，而不是函数本身。
- 用函数表达式声明第一行效果相同：`let sayHi = function() {...};`

**为什么函数表达式末尾有分号？**
- 分号不是函数语法的一部分，而是赋值语句 `let sayHi = ...;` 的结尾，就像 `let sayHi = 5;` 一样。函数声明是独立语句，不需要分号。

### 3. 回调函数
- 函数作为值可以作为**参数**传给另一个函数，期望在稍后必要时"回调"它。

```js
function ask(question, yes, no) {
  if (confirm(question)) yes()
  else no();
}

function showOk() {
  alert( "You agreed." );
}

function showCancel() {
  alert( "You canceled the execution." );
}

// showOk 和 showCancel 作为参数传入 ask
ask("Do you agree?", showOk, showCancel);
```

- `showOk`、`showCancel` 称为**回调函数**（callback）。
- 用函数表达式可以写得更简洁——直接在调用处创建**匿名函数**：

```js
ask(
  "Do you agree?",
  function() { alert("You agreed."); },
  function() { alert("You canceled the execution."); }
);
```

- 这两个函数没有名字，在 `ask` 外无法访问（没有赋给变量），这正是想要的。这种代码在 JS 中非常常见，符合语言思想。
- **函数是表示"行为"的值**：字符串、数字等常规值代表**数据**，函数代表**行为**，可以在变量间传递并在需要时运行。

### 4. 函数表达式 vs 函数声明
**语法区别**：
- **函数声明**：在主代码流中作为**单独语句**声明。

```js
function sum(a, b) {
  return a + b;
}
```

- **函数表达式**：在表达式中或其他语法结构中创建。

```js
let sum = function(a, b) {
  return a + b;
};
```

**创建时机的区别**：

| | 函数声明 | 函数表达式 |
|---|---|---|
| 何时创建 | 脚本/代码块**执行前**的"初始化阶段" | 代码**执行到**时才创建 |
| 声明前能否调用 | **能** | 不能（报错） |
| 作用域 | 严格模式下限于所在**代码块** | 跟随所赋值的变量 |

- 函数声明在定义之前就可以调用（引擎准备运行脚本时先找全局函数声明并创建它们，之后才执行代码）：

```js
sayHi("John"); // Hello, John

function sayHi(name) {
  alert( `Hello, ${name}` );
}
```

- 函数表达式则不行：

```js
sayHi("John"); // error!

let sayHi = function(name) {  // (*) 执行到这里才创建
  alert( `Hello, ${name}` );
};
```

**块级作用域**：严格模式下，代码块内的函数声明只在该代码块内可见，块外不可见。

```js
let age = prompt("What is your age?", 18);

if (age < 18) {
  function welcome() {
    alert("Hello!");
  }
} else {
  function welcome() {
    alert("Greetings!");
  }
}

welcome(); // Error: welcome is not defined
```

- 在 `if` 块内部，函数声明在**块内任意位置**（包括声明之前）都可用，但出了块就不可见。
- 要让 `welcome` 在块外可见，用**函数表达式**赋给块外声明的变量：

```js
let age = prompt("What is your age?", 18);

let welcome;

if (age < 18) {
  welcome = function() {
    alert("Hello!");
  };
} else {
  welcome = function() {
    alert("Greetings!");
  };
}

welcome(); // 现在可以了
```

- 用 `?` 进一步简化：

```js
let welcome = (age < 18) ?
  function() { alert("Hello!"); } :
  function() { alert("Greetings!"); };

welcome();
```

**什么时候选哪个？**
- 需要声明函数时**首先考虑函数声明**：可以在声明前调用，代码组织更灵活；`function f(…) {…}` 比 `let f = function(…) {…}` 更醒目、更易查找。
- 函数声明不适合时（如上面的条件创建、作为参数传递等）才用函数表达式。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| 方法不是值，不能赋给变量 | 函数是**一等公民**（first-class），可以赋值、复制、传参、返回 | 这是 JS 与 Java 最根本的差异之一 |
| Java 8 lambda / 方法引用 `Foo::bar` 需要函数式接口类型 | `let f = sayHi;` 直接复制，无需接口 | 概念上类似方法引用，但 JS 不需要声明 `Runnable`/`Function<T,R>` 之类的类型 |
| 匿名内部类 `new Runnable() { public void run() {...} }` | 匿名函数表达式 `function() {...}` | 回调写法的对应物，JS 简洁得多 |
| 回调需要接口约定（`Callback` 接口） | 任何函数都可以作为回调 | 鸭子类型，只要能调用即可 |
| 方法在类加载时就存在，调用顺序无关 | 函数**声明**类似（提升，先创建再执行）；函数**表达式**必须先赋值后调用 | 区分两者的创建时机是本篇重点 |
| 提到方法名不加括号是编译错误 | `sayHi` 是函数值，`sayHi()` 是调用 | 忘加括号是把函数本身传出去，是常见 bug 来源，也是常见的有意用法 |
| 无块级方法 | 严格模式下代码块内的函数声明只在块内可见 | 条件创建函数时用函数表达式 |
| `System.out.println(method)` 不合法 | `alert(sayHi)` 输出函数源码 | 函数值可以被打印 |

**实践建议**：
- 顶层/主流程的函数用函数声明；作为参数、条件创建、赋值给对象属性时用函数表达式（或下一篇的箭头函数）。
- 传函数时不要手滑加括号：`ask(q, showOk, showCancel)` 传的是函数，`ask(q, showOk(), showCancel())` 传的是调用结果。
- 后续学到的数组方法（`forEach`、`map`、`filter`）、事件处理、定时器都建立在"函数是值 + 回调"这个概念上。

## 一句话总结
函数是值：可以赋给变量、复制、作为参数传递（回调）、匿名创建；函数声明在代码执行前就被创建、声明前可调用但严格模式下限于所在代码块，函数表达式执行到时才创建；默认用函数声明，需要条件创建或传参时用函数表达式。

# 17 箭头函数，基础知识

> 原文：`zh.javascript.info/1-js/02-first-steps/17-arrow-functions-basics/article.md`
> ES6 新语法，是现代 JS 代码中最常见的函数写法之一。

## 知识点

### 1. 基本语法
- 创建函数的第三种语法，通常比函数表达式更好，因为像箭头所以叫**箭头函数**：

```js
let func = (arg1, arg2, ..., argN) => expression;
```

- 含义：创建函数 `func`，接受参数 `arg1..argN`，对右侧 `expression` 求值并**返回结果**。等价于：

```js
let func = function(arg1, arg2, ..., argN) {
  return expression;
};
```

- 具体例子：

```js
let sum = (a, b) => a + b;

/* 等价于：
let sum = function(a, b) {
  return a + b;
};
*/

alert( sum(1, 2) ); // 3
```

### 2. 参数的几种形式
| 参数数量 | 写法 | 示例 |
|---|---|---|
| 多个 | 必须加括号 | `(a, b) => a + b` |
| 一个 | **可以省略括号** | `n => n * 2` |
| 零个 | 括号为空，**必须保留** | `() => alert("Hello!")` |

```js
let double = n => n * 2;
// 差不多等同于：let double = function(n) { return n * 2 }
alert( double(3) ); // 6

let sayHi = () => alert("Hello!");
sayHi();
```

### 3. 像函数表达式一样使用
- 箭头函数可以出现在任何函数表达式能出现的地方，例如动态创建：

```js
let age = prompt("What is your age?", 18);

let welcome = (age < 18) ?
  () => alert('Hello!') :
  () => alert("Greetings!");

welcome();
```

- 一开始可能不习惯、不好读，看习惯后很快就会改变。
- 特别适合**简单的单行行为**，以及作为回调。

### 4. 多行的箭头函数
- 需要多行语句时，用花括号 `{}` 包起来；**用了花括号就必须显式 `return`** 才能返回值（和常规函数一样）：

```js
let sum = (a, b) => {  // 花括号表示开始一个多行函数
  let result = a + b;
  return result;       // 用了花括号，需要显式 return
};

alert( sum(1, 2) ); // 3
```

### 5. 两种形式对比
| 形式 | 写法 | 返回值 |
|---|---|---|
| 不带花括号 | `(...args) => expression` | 自动返回 `expression` 的值 |
| 带花括号 | `(...args) => { body }` | 需要显式 `return`，否则返回 `undefined` |

### 6. 更多内容
- 箭头函数还有其他有趣特性（如没有自己的 `this`、没有 `arguments`、不能作为构造函数），需要先学 JS 其他知识，后续 `arrow-functions` 章节再深入。
- 目前掌握：用箭头函数写单行行为和回调。

### 7. 补充：一个常见坑（原文未提，实践中高频）
- 想要直接返回**对象字面量**时，`{}` 会被解析为函数体而不是对象，需要用括号包起来：

```js
let makeUser = (name) => ({ name: name, age: 18 }); // 正确：返回对象
// let makeUser = (name) => { name: name };          // 错误：{} 被当成函数体，返回 undefined
```

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| Lambda：`(a, b) -> a + b` | 箭头函数：`(a, b) => a + b` | 概念几乎一样，符号是 `=>` 不是 `->` |
| 单参数可省括号：`n -> n * 2` | 相同：`n => n * 2` | 一致 |
| 零参数：`() -> ...` | 相同：`() => ...` | 一致 |
| 多行需 `{}` + `return` | 相同 | 一致 |
| Lambda 必须匹配某个**函数式接口**（`Function`、`Runnable`、`Comparator`…） | 箭头函数就是普通函数值，不需要接口 | JS 没有类型约束，直接赋给变量或传参 |
| Lambda 中 `this` 指向外层实例 | 箭头函数没有自己的 `this`，继承外层 | 这点两者反而**一致**；JS 的普通 `function` 才有独立 `this`（后续详讲） |
| 直接返回对象：`() -> new Foo()` 无歧义 | `() => ({...})` 返回对象字面量要加括号 | JS 特有的语法歧义 |
| 只能捕获 effectively final 的外部变量 | 可以读写任意外层变量 | JS 闭包没有 final 限制 |
| 不能替代所有方法（无法作为构造器等） | 箭头函数也不能作为构造函数、没有 `arguments` | 后续章节讲 |

**实践建议**：
- 回调、单行工具函数、数组方法（`arr.map(x => x * 2)`）优先用箭头函数。
- 顶层主流程函数、需要 `this` 的对象方法仍用 `function`（原因后续讲 `this` 时会清楚）。
- 返回对象字面量记得加括号 `({...})`。

## 一句话总结
`(args) => expression` 是函数表达式的简写，自动返回右侧表达式的值；单参数可省括号、零参数括号必留；带 `{}` 的多行形式需要显式 `return`；语法与 Java lambda 几乎一样但不需要函数式接口；适合单行行为和回调。

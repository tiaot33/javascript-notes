# 12 空值合并运算符 '??'

> 原文：`zh.javascript.info/1-js/02-first-steps/12-nullish-coalescing-operator/article.md`
> ES2020 新增，较新的语法，旧浏览器不支持。

## 知识点

### 1. 定义
- 术语约定：一个值既不是 `null` 也不是 `undefined`，称为"**已定义的（defined）**"。
- `a ?? b` 的结果：
  - `a` 已定义 → 返回 `a`
  - `a` 不是已定义（即 `null` 或 `undefined`） → 返回 `b`
- 用已知运算符重写，语义完全等价：

```js
result = (a !== null && a !== undefined) ? a : b;
```

- `??` 不是全新概念，只是"取两者中第一个已定义的值"的简洁语法。

### 2. 常见场景：提供默认值

```js
let user;
alert(user ?? "匿名"); // 匿名（user 是 undefined）

let user2 = "John";
alert(user2 ?? "匿名"); // John（已定义）
```

- 可以串联，从一系列值中选出第一个非 `null/undefined` 的值：

```js
let firstName = null;
let lastName = null;
let nickName = "Supercoder";

alert(firstName ?? lastName ?? nickName ?? "匿名"); // Supercoder
```

- 给变量赋默认值的惯用写法：

```js
// height 为 null 或 undefined 时设为 100
height = height ?? 100;
```

### 3. 与 `||` 比较
- `||` 也能做同样的事，而且历史更久（JS 诞生就有），开发者长期用它设默认值：

```js
alert(firstName || lastName || nickName || "Anonymous"); // Supercoder
```

- `??` 是因为人们对 `||` 不满意才加进来的。**关键区别**：
  - `||` 返回第一个**真**值。
  - `??` 返回第一个**已定义的**值。
- `||` 无法区分 `false`、`0`、`""` 与 `null/undefined`——它们都是假值，都会被替换成默认值。但实际中我们往往**只想在值确实未设置（`null/undefined`）时才用默认值**：

```js
let height = 0;

alert(height || 100); // 100  ← 0 是假值，被替换了
alert(height ?? 100); // 0    ← 0 不是 null/undefined，保留
```

- 高度 `0` 通常是有效值，不应被替换，所以这里 `??` 才是正确的。

| 运算符 | 何时取右边 | 对 `0`/`""`/`false` |
|---|---|---|
| `a \|\| b` | `a` 是假值 | 会被替换成 `b` |
| `a ?? b` | `a` 是 `null` 或 `undefined` | 保留 `a` |

### 4. 优先级
- `??` 优先级与 `||` 相同（都是 3）：比 `=` 和 `?` 高，但比 `+`、`*` 等大多数运算符**低**。
- 所以在算术表达式中要**加括号**：

```js
let height = null;
let width = null;

// 重要：使用括号
let area = (height ?? 100) * (width ?? 50);
alert(area); // 5000
```

- 不加括号时 `*` 先执行，变成不符合预期的 `height ?? (100 * width) ?? 50`。

### 5. `??` 与 `&&`、`||` 一起使用
- 出于安全原因，**JS 禁止 `??` 与 `&&`、`||` 直接混用**，除非用括号明确优先级，否则是语法错误：

```js
let x = 1 && 2 ?? 3; // SyntaxError
```

- 加括号即可：

```js
let x = (1 && 2) ?? 3; // 正常
alert(x); // 2
```

- 这个限制是为了避免人们从 `||` 切换到 `??` 时犯错，规范层面有争议，但事实如此。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `x != null ? x : defaultValue` | `x ?? defaultValue` | 语义最接近，JS 额外覆盖 `undefined` |
| `Optional.ofNullable(x).orElse(defaultValue)` | `x ?? defaultValue` | 不需要包装类型，一个运算符搞定 |
| `Objects.requireNonNullElse(x, def)`（Java 9） | `x ?? def` | 同上 |
| 无 Elvis 运算符（Kotlin/Groovy 的 `?:` 才有） | `??` | 概念等同 Kotlin 的 `a ?: b` |
| `0`、`""`、`false` 是普通值，判空只看 `null` | `\|\|` 会把它们当"空"，`??` 不会 | Java 直觉对应 `??`，而不是 `\|\|` |
| 无对应 | `??` 不能与 `&&`/`\|\|` 无括号混用 | 语法错误，写的时候加括号即可 |
| 无对应 | `??=`（ES2021）：`x ??= 100` 等价 `x = x ?? 100` | 原文未提，与 `+=` 类似的复合赋值形式，可顺带记住 |

**实践建议**：
- 设默认值时，**优先用 `??`**，只有当确实想把 `0`/`""`/`false` 也替换掉时才用 `||`。
- 与算术运算混合时加括号；与 `&&`/`||` 混合时必须加括号。
- 需要考虑兼容旧浏览器（IE、2020 年前的浏览器）时需要 Babel 转译。

## 一句话总结
`a ?? b` 在 `a` 为 `null/undefined` 时取 `b`，否则保留 `a`（包括 `0`/`""`/`false`），是设默认值的正确选择；与 `||` 的区别是"已定义"而不是"真值"；优先级低要加括号，与 `&&`/`||` 混用必须加括号。

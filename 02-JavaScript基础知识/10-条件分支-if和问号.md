# 10 条件分支：if 和 '?'

> 原文：`zh.javascript.info/1-js/02-first-steps/10-ifelse/article.md`

## 知识点

### 1. `if` 语句
- `if (...)` 计算括号内的条件表达式，结果为 `true` 时执行对应代码块。

```js
let year = prompt('In which year was ECMAScript-2015 specification published?', '');

if (year == 2015) alert( 'You are right!' );
```

- 多条语句必须用大括号 `{}` 包起来。
- **建议即使只有一条语句也始终加 `{}`**，提高可读性。

```js
if (year == 2015) {
  alert( "That's correct!" );
  alert( "You're so smart!" );
}
```

### 2. 布尔转换
- `if (…)` 会把括号内表达式的结果**转换为布尔型**（复习 07 类型转换）：
  - 假值（falsy）：`0`、`""`、`null`、`undefined`、`NaN` → `false`
  - 其他值都是真值（truthy） → `true`

```js
if (0) { ... } // 永远不执行
if (1) { ... } // 始终执行
```

- 也可以先把布尔值算好存进变量再传入：

```js
let cond = (year == 2015);
if (cond) { ... }
```

### 3. `else` 语句
- 可选的 `else` 块，条件不成立时执行。

```js
if (year == 2015) {
  alert( 'You guessed it right!' );
} else {
  alert( 'How can you be so wrong?' );
}
```

### 4. 多个条件：`else if`
- 依次检查多个条件，第一个成立的分支执行；可以有任意多个 `else if`，结尾的 `else` 可选。

```js
if (year < 2015) {
  alert( 'Too early...' );
} else if (year > 2015) {
  alert( 'Too late' );
} else {
  alert( 'Exactly!' );
}
```

### 5. 条件运算符 `?`（三元运算符）
- 根据条件给变量赋值时，比 `if...else` 更简短。
- 语法：`let result = condition ? value1 : value2;` —— 条件为真返回 `value1`，否则返回 `value2`。
- 之所以叫"三元"，是因为有三个操作数，是 JS 中**唯一**有这么多操作数的运算符。

```js
// if 版本
let accessAllowed;
if (age > 18) {
  accessAllowed = true;
} else {
  accessAllowed = false;
}

// ? 版本
let accessAllowed = (age > 18) ? true : false;
```

- `?` 优先级较低，`age > 18` 外面的括号技术上可以省略，但**建议保留括号**增强可读性。
- 上面这个例子其实不需要 `?`，比较本身就返回布尔值：`let accessAllowed = age > 18;`

### 6. 多个 `?`（链式三元）
- 一系列 `?` 可以根据多个条件返回值，本质是一个顺序检查序列：

```js
let age = prompt('age?', 18);

let message = (age < 3) ? 'Hi, baby!' :
  (age < 18) ? 'Hello!' :
  (age < 100) ? 'Greetings!' :
  'What an unusual age!';

alert( message );
```

- 执行过程：检查 `age < 3`，真则返回 `'Hi, baby!'`，否则继续检查冒号后的 `age < 18`……以此类推，最后一个冒号后是兜底值。
- 等价的 `if..else if..else` 写法：

```js
if (age < 3) {
  message = 'Hi, baby!';
} else if (age < 18) {
  message = 'Hello!';
} else if (age < 100) {
  message = 'Greetings!';
} else {
  message = 'What an unusual age!';
}
```

### 7. `?` 的非常规使用（不推荐）
- 有人用 `?` 代替 `if` 来执行不同代码而不是取值：

```js
(company == 'Netscape') ?
   alert('Right!') : alert('Wrong.');
```

- **不建议这样用**：更短但可读性差。眼睛是纵向扫描代码的，跨越几行的代码块比又长又横的一行更易读。
- 原则：**`?` 用于根据条件返回一个值；要执行不同代码分支时用 `if`。**

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `if (cond)` 中 `cond` 必须是 `boolean` | `if (cond)` 中任何值都会被转成布尔 | `if (str)`、`if (count)` 在 JS 里合法且常用，意思是"非空字符串 / 非零" |
| `if (obj != null)` | `if (obj)` | JS 惯用简写，但注意 `0`、`""` 也是假值，如果这些是合法值就不能这么写 |
| `if / else if / else` 语法相同 | 相同 | 完全一致 |
| `cond ? a : b` 三元运算符相同，两个分支类型需兼容 | 相同，两个分支可以是任意类型 | 动态类型，`x ? 1 : "a"` 合法 |
| 链式三元同样可以 | 相同 | 同样的可读性问题，超过两层建议改 `if` 或 `switch` |
| 三元表达式不能作为独立语句（`cond ? f() : g();` 编译错误） | 可以作为语句执行 | JS 允许但不推荐，要执行分支就用 `if` |
| `if (year == 2015)` 比较 `int` | `if (year == 2015)` 中 `year` 是 `prompt` 返回的**字符串** | 例子里之所以能用是因为 `==` 自动转数字；实际写法应先 `Number()` 再 `===` |

**实践建议**：
- `if` 后永远加 `{}`，哪怕只有一行。
- 利用 truthy/falsy 简写 `if (x)` 时，先确认 `0`/`""` 不是该变量的合法值。
- 三元只用于取值，不用于执行副作用；链式三元不超过两层。

## 一句话总结
`if / else if / else` 与 Java 相同，但条件会做布尔转换（假值只有 5 个）；`cond ? a : b` 用于按条件取值，可以链式但别太长，要执行不同代码分支请用 `if`。

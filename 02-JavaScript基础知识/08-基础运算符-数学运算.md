# 08 基础运算符，数学运算

> 原文：`zh.javascript.info/1-js/02-first-steps/08-operators/article.md`

## 知识点

### 1. 术语：运算元、一元运算符、二元运算符
- **运算元（operand）**：运算符作用的对象，`5 * 2` 有左运算元 `5` 和右运算元 `2`，也叫"参数"。
- **一元运算符**：只有一个运算元，如一元负号 `-x`。
- **二元运算符**：两个运算元，如 `y - x`。
- 同一个符号可以代表两个不同的运算符（一元负号 vs 二元减法）。

```js
let x = 1;
x = -x;
alert( x ); // -1，一元负号

let a = 1, b = 3;
alert( b - a ); // 2，二元减法
```

### 2. 数学运算
| 运算 | 符号 |
|---|---|
| 加 | `+` |
| 减 | `-` |
| 乘 | `*` |
| 除 | `/` |
| 取余 | `%` |
| 求幂 | `**` |

- **取余 `%`**：`a % b` 是 `a` 除以 `b` 的余数，与百分数无关。

```js
alert( 5 % 2 ); // 1
alert( 8 % 3 ); // 2
```

- **求幂 `**`**（ES2016）：`a ** b` 即 a 的 b 次方，也支持非整数指数（开方）。

```js
alert( 2 ** 2 ); // 4
alert( 2 ** 3 ); // 8
alert( 4 ** (1/2) ); // 2，1/2 次方即平方根
alert( 8 ** (1/3) ); // 2，立方根
```

### 3. 用二元 `+` 连接字符串
- `+` 应用于字符串时是拼接。**只要任意一个运算元是字符串，另一个也会被转成字符串**：

```js
alert( '1' + 2 ); // "12"
alert( 2 + '1' ); // "21"
```

- 运算符**按顺序（从左到右）**执行，因此位置很重要：

```js
alert( 2 + 2 + '1' ); // "41"，不是 "221"：先 2+2=4，再 4+'1'="41"
alert( '1' + 2 + 2 ); // "122"，不是 "14"：先 '1'+2="12"，再 "12"+2="122"
```

- **二元 `+` 是唯一这样支持字符串的运算符**。其他算术运算符只对数字起作用，总是把运算元转成数字：

```js
alert( 6 - '2' );   // 4
alert( '6' / '2' ); // 3
```

### 4. 数字转化：一元 `+`
- 一元 `+` 对数字无效果，对非数字则转成数字，**效果与 `Number(...)` 相同但更短**。

```js
let x = 1;
alert( +x ); // 1

alert( +true ); // 1
alert( +"" );   // 0
```

- 典型场景：表单取到的是字符串，直接 `+` 会拼接，先用一元 `+` 转数字再相加：

```js
let apples = "2";
let oranges = "3";

alert( apples + oranges );   // "23"，字符串拼接
alert( +apples + +oranges ); // 5，一元 + 先把两者转成数字，再做二元加法
// 等价的长写法：Number(apples) + Number(oranges)
```

- 一元 `+` 先于二元 `+` 执行，因为一元运算符**优先级更高**。

### 5. 运算符优先级
- 多个运算符时按优先级决定顺序，数字越大越先执行；相同优先级从左到右。
- 圆括号优先级最高，可用来改变顺序。
- 摘自 MDN 的部分优先级表（不必全记，**记住一元运算符高于二元运算符**）：

| 优先级 | 名称 | 符号 |
|---|---|---|
| 15 | 一元加号 | `+` |
| 15 | 一元负号 | `-` |
| 14 | 求幂 | `**` |
| 13 | 乘 / 除 | `*` `/` |
| 12 | 加 / 减 | `+` `-` |
| 2 | 赋值 | `=` |

### 6. 赋值运算符 `=`
- `=` 也是运算符，优先级很低（2），所以 `x = 2 * 2 + 1` 先算右边再赋值。

**赋值会返回一个值**：`x = value` 把 `value` 写入 `x` 然后**返回 `value`**，因此可以嵌在表达式里。

```js
let a = 1;
let b = 2;

let c = 3 - (a = b + 1);

alert( a ); // 3
alert( c ); // 0
```

- 能看懂即可（某些库里会出现），**不要写这种代码**，不利于可读性。

**链式赋值**：从右到左计算，所有变量共享同一个值。

```js
let a, b, c;
a = b = c = 2 + 2;
alert( a ); // 4
alert( b ); // 4
alert( c ); // 4
```

- 出于可读性，建议拆成多行：`c = 2 + 2; b = c; a = c;`

### 7. 原地修改（复合赋值）
- `+=`、`-=`、`*=`、`/=` 等，所有算术和位运算符都有对应形式。

```js
let n = 2;
n += 5; // n = 7
n *= 2; // n = 14
```

- 优先级与 `=` 相同（很低），右边整体先算：

```js
let n = 2;
n *= 3 + 5;
alert( n ); // 16，等同于 n *= 8
```

### 8. 自增 / 自减 `++` `--`
- 只能作用于**变量**，`5++` 会报错。
- **前置形式** `++counter` 返回**新值**；**后置形式** `counter++` 返回**旧值**。两者都会让变量加 1，区别只在返回值。

```js
let counter = 1;
let a = ++counter; // a = 2，counter = 2

let counter2 = 1;
let b = counter2++; // b = 1，counter2 = 2
```

- 三种使用情况：
  - 不使用返回值：两种形式没区别。
  - 自增后立刻用新值：用前置 `alert( ++counter ); // 1`
  - 加一但要用旧值：用后置 `alert( counter++ ); // 0`
- `++/--` 可用在表达式内部，优先级高于大部分算术运算符：

```js
let counter = 1;
alert( 2 * ++counter ); // 4
alert( 2 * counter++ ); // 2（如果 counter 重新从 1 开始），因为返回旧值
```

- 建议"**一行一个行为**"，不要把 `counter++` 塞进表达式里，纵向扫代码时容易漏掉。

### 9. 位运算符
- 把运算元当作 **32 位整数**，在二进制位上操作。
- `&` 按位与、`|` 按位或、`^` 按位异或、`~` 按位非、`<<` 左移、`>>` 右移、`>>>` 无符号右移。
- Web 开发很少用，密码学等领域有用。需要时查 MDN。

### 10. 逗号运算符 `,`
- 分隔多个表达式，**每个都会执行，但只返回最后一个的结果**。

```js
let a = (1 + 2, 3 + 4);
alert( a ); // 7
```

- **优先级极低，比 `=` 还低**，所以上面的括号必不可少。没有括号时 `a = 1 + 2, 3 + 4` 等价于 `(a = 1 + 2), 3 + 4`，`a` 得到 `3`。
- 常见于 `for` 头部一行做多个操作：`for (a = 1, b = 3, c = a * b; a < 10; a++) {...}`
- 一些框架里会用，但通常不利于可读性，使用前想清楚。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `Math.pow(a, b)` | `a ** b` | ES2016 新增运算符，也可用 `Math.pow` |
| `5 / 2` → `2`（整数除法） | `5 / 2` → `2.5` | JS 只有浮点数，没有整数除法；要取整用 `Math.floor`/`Math.trunc` |
| `"1" + 2` → `"12"`，`"6" - "2"` 编译错误 | `"1" + 2` → `"12"`，`6 - "2"` → `4` | 二元 `+` 遇字符串拼接的行为相同；但 JS 其他算术运算符会把字符串转数字而不是报错 |
| `int x = +"3";` 编译错误 | `+"3"` → `3` | 一元 `+` 是常用的字符串转数字简写 |
| `x = y = 5` 同样支持链式赋值、赋值返回值 | 相同 | 语法一致，同样不推荐嵌在表达式里 |
| `++`/`--` 前置后置语义相同 | 相同 | 完全一致 |
| `+=` 等复合赋值相同 | 相同 | JS 的 `+=` 遇字符串也会变成拼接 |
| 位运算符符号相同，`>>>` 也有 | 相同，但 JS 强制转 32 位整数 | JS 没有 `long`，位运算超过 32 位会截断 |
| 逗号只用于 `for` 头部和声明多变量，**不是运算符** | 逗号是运算符，可出现在任意表达式里 | `let a = (1 + 2, 3 + 4)` 在 Java 里不合法 |
| 表达式中 `int` 溢出回绕 | 不回绕，超过 2^53 精度丢失 | 见 05 数据类型 |

**实践建议**：
- 从字符串源拿到数字时，先 `+str` 或 `Number(str)` 再参与 `+` 运算，否则会变成拼接。
- 除法结果默认是小数，需要整数时显式取整。
- 不要在表达式里嵌赋值、逗号运算符、`counter++`，一行一件事。

## 一句话总结
JS 算术运算符与 Java 基本一致，多了 `**`；两个最大差别是：除法永远是浮点除法，以及二元 `+` 遇字符串会拼接而其他算术运算符会把字符串转数字；一元 `+` 是 `Number()` 的简写；赋值、`++/--`、复合赋值、位运算与 Java 相同，逗号在 JS 里是真正的运算符。

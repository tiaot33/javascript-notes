# 03 静态属性和静态方法

> 原文：`zh.javascript.info/1-js/09-classes/03-static-properties-methods/article.md`
> `static` 的用法与 Java 相近，真正的新知识是**静态成员如何被继承**：`extends` 其实设置了两条原型链，一条给实例方法，一条给静态方法。这也是 JS 静态方法里 `this` 有意义、且能多态的原因。

## 知识点

### 1. 静态方法
```js
class User {
  static staticMethod() {
    alert(this === User); // true
  }
}
User.staticMethod();

// 完全等价于直接给类（函数）赋属性：
User.staticMethod = function() { alert(this === User); };
```
- 静态方法是**挂在类（构造函数）本身上的属性**，不在 `prototype` 上，实例访问不到：`user.staticMethod()` → `is not a function`。
- 调用 `User.staticMethod()` 时 `this === User`，仍是"点号前的对象"规则。

### 2. 典型用途
- **比较器**：`Article.compare(a, b)` 用于 `articles.sort(Article.compare)`，它"属于文章这个概念"而不属于某一篇文章。
- **工厂方法**：

```js
class Article {
  constructor(title, date) { this.title = title; this.date = date; }
  static createTodays() {
    return new this("Today's digest", new Date()); // this = Article
  }
}
let article = Article.createTodays();
```
- **类级别的数据访问**：如 `Article.remove({id: 12345})` 这类围绕数据库表的操作。
- 注意 `new this(...)`：因为 `this` 是被调用的那个类，子类 `Rabbit.createTodays()` 造出来的是 `Rabbit` 实例，静态方法天然多态。

### 3. 静态属性
```js
class Article {
  static publisher = "Levi Ding";
}
Article.publisher; // "Levi Ding"
// 等价于 Article.publisher = "Levi Ding";
```
较新的语法（与类字段同期），语义就是给类对象加一个属性。补充（教程未提）：ES2022 还有 `static { ... }` 静态初始化块，用于复杂的类级初始化。

### 4. 静态成员的继承：`extends` 设置了两条链
```js
class Animal {
  static planet = "Earth";
  static compare(a, b) { return a.speed - b.speed; }
  constructor(name, speed) { this.name = name; this.speed = speed; }
}
class Rabbit extends Animal {}

rabbits.sort(Rabbit.compare); // 用的是继承来的 Animal.compare
Rabbit.planet;                // "Earth"
```
`class Rabbit extends Animal` 创建了**两个** `[[Prototype]]` 引用：

```js
Rabbit.__proto__ === Animal;                     // true  ← 静态成员走这条链
Rabbit.prototype.__proto__ === Animal.prototype; // true  ← 实例方法走这条链
```
```
Rabbit ──[[Prototype]]──▶ Animal ──[[Prototype]]──▶ Function.prototype
  │ .prototype                │ .prototype
  ▼                           ▼
Rabbit.prototype ──[[Prototype]]──▶ Animal.prototype ──[[Prototype]]──▶ Object.prototype
```
- 读 `Rabbit.compare` 在 `Rabbit` 上没找到，沿 `Rabbit.__proto__` 到 `Animal` 找到。
- 坑（由原型规则推出）：**写**静态属性只作用于自身。`Rabbit.planet = "Mars"` 在 `Rabbit` 上创建自己的属性，`Animal.planet` 仍是 `"Earth"`，二者从此分道扬镳。想共享可变的类级状态要显式写 `Animal.planet = ...`。

### 5. 练习题要点：`class Rabbit extends Object` 与 `class Rabbit` 的区别
| | `class Rabbit` | `class Rabbit extends Object` |
|---|---|---|
| 自定义 constructor | 不需要 `super()` | **必须调 `super()`**，否则 `this` 未定义 |
| `Rabbit.__proto__` | `Function.prototype`（所有函数的默认原型） | `Object` |
| `Rabbit.getOwnPropertyNames(...)` | Error，没有这个静态方法 | 可用，继承了 `Object` 的静态方法 |
| `Rabbit.prototype.__proto__` | `Object.prototype` | `Object.prototype`（相同） |

- 实例方法层面两者没区别，`rabbit.hasOwnProperty` 都来自 `Object.prototype`。
- `Function.prototype` 上的 `call/apply/bind` 两种情况都能用，因为 `Object.__proto__ === Function.prototype`。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `static` 方法属于类，通过类名调用 | 同 | 一致，实例上同样调不到 |
| 静态方法里**没有** `this` | `this` = 调用时点号前的类 | JS 静态方法可以 `new this()`，子类调用得到子类实例，Java 做不到 |
| 静态方法不参与多态（编译期按类型解析） | 静态方法沿 `Rabbit.__proto__ → Animal` 链查找，子类可**重写**静态方法并被 `this` 多态调用 | JS 的"静态"只是"挂在类对象上"，本质还是对象属性 |
| `static` 字段全局唯一，`Rabbit.planet = "Mars"` 改的就是 `Animal.planet` | 子类写静态属性会创建自己的属性并遮蔽父类 | 见第 4 点，共享可变状态时要写父类名 |
| 没有"继承 Object 的静态方法"这种事 | `class X extends Object` 会让 `X.__proto__ === Object`，获得 `Object.keys` 等静态方法 | 练习题的差异 |
| 静态初始化块 `static { ... }` | ES2022 同样有 `static { ... }` | 语法一致 |
| 工厂方法 `static of(...)`、比较器 `Comparator` | `static create...()`、`static compare(a, b)` 给 `sort` 用 | 用法思路一致 |

## 一句话总结
`static method()` / `static prop = v` 等价于直接给类（函数）对象赋属性，实例访问不到，调用时 `this` 是类本身，因此 `new this()` 形式的工厂在子类上调用得到子类实例；`class B extends A` 设置**两条**原型链，`B.__proto__ = A` 让静态成员可继承，`B.prototype.__proto__ = A.prototype` 让实例方法可继承；读静态属性沿链查找，写则只在自身创建属性；普通 `class X` 的 `X.__proto__` 是 `Function.prototype`，只有 `extends Object` 才会拿到 `Object` 的静态方法（同时构造器里必须调 `super()`）。

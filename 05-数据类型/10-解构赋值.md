# 10 解构赋值

> 原文：`zh.javascript.info/1-js/05-data-types/10-destructuring-assignment/article.md`
> **ES6 核心语法**，现代 JS 代码中随处可见，重点掌握。

## 知识点

### 0. 什么是解构赋值
把数组或对象"拆包"到一系列变量中的特殊语法。只是简洁写法，**不修改原数组/对象**：

```js
let [firstName, surname] = arr;
// 等价于：let firstName = arr[0]; let surname = arr[1];
```

### 1. 数组解构
```js
let [firstName, surname] = "John Smith".split(' '); // 与返回数组的函数配合很优雅
```

**细节**：
- **逗号跳过元素**：`let [firstName, , title] = ["Julius", "Caesar", "Consul"]` → title = "Consul"。
- **右侧可以是任何可迭代对象**：`let [a,b,c] = "abc"`、`let [x,y,z] = new Set([1,2,3])`（本质是对右侧跑 `for..of` 的语法糖）。
- **左侧可以是任何可赋值的东西**，比如对象属性：

```js
let user = {};
[user.name, user.surname] = "John Smith".split(' ');
```

- **与 entries() 配合遍历**（高频用法）：

```js
for (let [key, value] of Object.entries(user)) { ... }
// Map 更简单，它本身就可迭代：
for (let [key, value] of userMap) { ... }
```

- **交换变量技巧**：

```js
[guest, admin] = [admin, guest]; // 不需要临时变量
```

### 2. 剩余元素 `...rest`
```js
let [name1, name2, ...rest] = ["Julius", "Caesar", "Consul", "of the Roman Republic"];
// rest = ["Consul", "of the Roman Republic"]（真数组）
```
- 名字任意，但必须带 `...` 且在**最后一个位置**。

### 3. 默认值
- 数组比左侧短不报错，缺的是 `undefined`。
- 用 `=` 提供默认值，**只在对应值为 undefined 时才计算**（可以是表达式甚至函数调用）：

```js
let [name = "Guest", surname = "Anonymous"] = ["Julius"];
// name = "Julius"，surname = "Anonymous"

let [name = prompt('name?'), surname = prompt('surname?')] = ["Julius"];
// prompt 只对缺失的 surname 执行
```

### 4. 对象解构
```js
let options = { title: "Menu", width: 100, height: 200 };
let {title, width, height} = options; // 按属性名匹配，顺序无所谓
```

**完整语法**：
```js
let {prop: varName = defaultValue, ...rest} = object
```

- **冒号改名**：`let {width: w, height: h, title} = options` → w=100, h=200。
- **默认值**：`let {width = 100, height = 200, title} = {title: "Menu"}`。
- 两者结合：`let {width: w = 100} = options`。
- **只取需要的属性**：`let { title } = options;`。
- **剩余模式**：`let {title, ...rest} = options` → rest 是含剩余属性的新对象。

### 5. 陷阱：不用 let 时必须加括号
```js
let title, width, height;
{title, width, height} = {title: "Menu", width: 200, height: 100}; // ❌ 报错！
```
语句开头的 `{...}` 被解析成**代码块**。用括号包起来解决：

```js
({title, width, height} = {title: "Menu", width: 200, height: 100}); // ✓
```

### 6. 嵌套解构
左侧模式与右侧结构保持一致，可取深层数据：

```js
let options = {
  size: { width: 100, height: 200 },
  items: ["Cake", "Donut"],
  extra: true
};

let {
  size: { width, height },   // size 本身没有对应变量，取的是它的内容
  items: [item1, item2],
  title = "Menu"             // 不存在 → 用默认值
} = options;
```

### 7. 智能函数参数（高频实战用法）
参数多且大多可选时，不用一长串位置参数，改传**一个对象**并在函数签名里解构：

```js
function showMenu({title = "Untitled", width = 200, height = 100, items = []}) {
  // title、items 来自传入对象，width、height 用默认值
}

let options = { title: "My menu", items: ["Item1", "Item2"] };
showMenu(options);
```
- 避免了 `showMenu("My Menu", undefined, undefined, ["Item1"])` 这种丑写法。
- 也支持嵌套和冒号映射：

```js
function showMenu({
  title = "Untitled",
  width: w = 100,
  height: h = 200,
  items: [item1, item2]
}) { ... }
```

- ⚠️ **给整个参数对象加默认值 `= {}`**，否则无参调用会报错：

```js
function showMenu({ title = "Menu", width = 100, height = 200 } = {}) { ... }
showMenu(); // Menu 100 200 ✓（没有 = {} 的话这行会抛错）
```

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| 无解构赋值（Java 21 record 模式仅局部类似） | `let [a, b] = arr` / `let {x, y} = obj` | 全新语法，Python 解包更接近 |
| 交换变量要临时变量 | `[a, b] = [b, a]` | 一行搞定 |
| `Map.entry` 遍历：`for (var e : map.entrySet())` | `for (let [k, v] of map)` | 解构直接拆键值 |
| Builder 模式 / 参数对象 | 函数参数解构 `{a=1, b=2} = {}` | JS 用解构原生支持"命名可选参数"，不需要 Builder |
| 方法重载处理可选参数 | 默认值 `= defaultValue` | 只在 undefined 时生效 |

## 一句话总结
解构赋值用 `let [a, b, ...rest] = array` 和 `let {prop: varName = default, ...rest} = object` 把数组/对象拆包到变量；支持逗号跳过、默认值（undefined 时生效）、嵌套模式、剩余收集；遍历键值对 `for (let [k,v] of Object.entries(obj))` 和函数参数对象解构 `{title="x"} = {}` 是最高频的两个实战场景；不用 let 的解构赋值要用括号包住防"代码块"误判。

# 11 日期和时间

> 原文：`zh.javascript.info/1-js/05-data-types/11-date/article.md`

## 知识点

### 1. 创建 Date 对象的四种方式
```js
new Date()                       // 当前日期时间
new Date(milliseconds)           // 时间戳：1970-01-01 UTC+0 起的毫秒数
new Date(datestring)             // 字符串解析（同 Date.parse 的算法）
new Date(year, month, date?, hours?, minutes?, seconds?, ms?) // 本地时区组件
```

```js
new Date(0);                    // 1970-01-01 UTC+0
new Date(24 * 3600 * 1000);     // +24 小时 → 1970-01-02
new Date(-24 * 3600 * 1000);    // 之前是负时间戳

new Date(2011, 0, 1);           // 2011-01-01 00:00:00
new Date(2011, 0, 1, 2, 3, 4, 567);
```

⚠️ 组件构造的坑：
- **`month` 从 0 开始**（0 = 一月，11 = 十二月）！
- `year` 用 4 位数（2 位会被当 19xx）。
- 缺的组件默认：date=1，时分秒毫秒=0。
- ⚠️ **JS 时间戳是毫秒**，不是秒（和 Unix 时间戳秒级不同）。

### 2. 读取组件（全部基于本地时区）
- `getFullYear()` —— 4 位年份（**别用废弃的 `getYear()`**，可能返回 2 位）
- `getMonth()` —— **0~11**
- `getDate()` —— 当月几号，1~31
- `getHours()` / `getMinutes()` / `getSeconds()` / `getMilliseconds()`
- `getDay()` —— 星期几，**0 = 星期日**，6 = 星期六（无法改）
- UTC 版本：在 get 后插 UTC——`getUTCFullYear()`、`getUTCMonth()`、`getUTCHours()`……

两个没有 UTC 变体的特殊方法：
- `getTime()` —— 返回时间戳（毫秒）。
- `getTimezoneOffset()` —— 本地与 UTC 的时差（分钟）：UTC+3 返回 **-180**（注意符号是反的）。

### 3. 设置组件
- `setFullYear(year, [month], [date])`
- `setMonth(month, [date])`
- `setDate(date)`
- `setHours(hour, [min], [sec], [ms])` —— 可一次设多个，未提及的组件不变
- `setMinutes/ setSeconds/ setMilliseconds`
- `setTime(ms)` —— 直接设整个时间戳
- 除 `setTime` 外都有 UTC 变体（`setUTCHours()` 等）。

```js
let today = new Date();
today.setHours(0);          // 今天，小时变 0
today.setHours(0, 0, 0, 0); // 今天 00:00:00
```
⚠️ **Date 是可变对象**：set 系列直接修改原对象（不像 java.time 的不可变设计）。

### 4. 自动校准（Autocorrection）—— 超好用的特性
超出范围的值自动进位/借位：

```js
new Date(2013, 0, 32);           // 1 月 32 日 → 2 月 1 日

let date = new Date(2016, 1, 28);
date.setDate(date.getDate() + 2); // 28 Feb + 2 天 → 1 Mar 2016（闰年自动处理）

date.setDate(0);  // 上个月的最后一天！
date.setDate(-5); // 也可以负数
```
做"几天后/几小时后"的日期算术**不用自己算月份天数**，直接加。

### 5. 日期转数字与日期差值
- Date 转数字得到时间戳：`+date` === `date.getTime()`。
- **日期可以相减**，结果是毫秒差：

```js
let start = new Date();
// ...干活...
let end = new Date();
alert( `耗时 ${end - start} ms` );
```

### 6. `Date.now()`：只要时间戳就用它
```js
let start = Date.now(); // 当前时间戳，不创建 Date 对象
```
- 等价于 `new Date().getTime()`，但**更快、无中间对象、不给 GC 添压力**。
- 测时间间隔、游戏循环等场景首选。

### 7. 基准测试（Benchmarking）的注意事项
- 显式 `getTime()` 比隐式类型转换快（引擎优化更容易）。
- 单次测量不可靠（CPU 被其他进程抢占）→ **多轮交替运行取总耗时**。
- 引擎对"hot code"才优化 → 先**预热**再正式测。
- 微型基准测试整体要谨慎，引擎优化可能扭曲结果。

### 8. `Date.parse(str)`：从字符串读日期
格式：`YYYY-MM-DDTHH:mm:ss.sssZ`
- `T` 是日期和时间的分隔符。
- `Z` 是时区：`Z` 表示 UTC+0，或 `+-hh:mm`。
- 允许短格式：`YYYY-MM-DD`、`YYYY-MM`、`YYYY`。

```js
let ms = Date.parse('2012-01-26T13:51:50.417-07:00'); // 1327611110417
new Date(ms); // 时间戳 → Date 对象
```
- 格式不对返回 `NaN`。

### 9. 更高精度
- `Date` 精确到毫秒。
- 浏览器：`performance.now()` —— 页面加载起的毫秒数，精确到微秒（小数点后三位有效）。
- Node.js：`microtime` 模块等。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `java.util.Date` 月份也从 0 开始 | `new Date(y, m, d)` 月份 0~11 | 同款历史坑 |
| `Instant.now().toEpochMilli()` | `Date.now()` | 都是毫秒；JS 没有秒级时间戳 |
| `Instant`/`LocalDateTime` **不可变** | `Date` **可变**（setHours 改原对象） | JS Date 设计上更像老 `java.util.Date` + `Calendar` 合体 |
| `Duration.between(a, b).toMillis()` | `date2 - date1` | JS 直接相减得毫秒 |
| `System.currentTimeMillis()` | `Date.now()` | 一致 |
| `System.nanoTime()` | `performance.now()`（浏览器） | 高精度计时 |
| `OffsetDateTime.parse`（ISO 格式） | `Date.parse(str)` | 都是 ISO-8601 风格，失败 JS 给 NaN 不抛异常 |
| `ZoneOffset.getTotalSeconds()` | `getTimezoneOffset()` 分钟且符号相反 | UTC+8 时 JS 返回 -480 |
| `java.time` 丰富的日期算术 | 靠 setDate + 自动校准 | JS 原生 API 弱，复杂场景常用 dayjs/date-fns 等库 |

## 一句话总结
JS 用可变的 `Date` 对象表示日期时间，时间戳是**毫秒**；创建有四种方式，组件构造里**月份从 0 开始**；读取用 `getFullYear/getMonth/getDate/getDay`（周日=0），都有 UTC 变体；`setDate` 配合**自动校准**做日期加减最方便（`setDate(0)` 是上月最后一天）；日期相减得毫秒差，纯计时用 `Date.now()`；`Date.parse` 解析 ISO 格式字符串。

# 05 数组方法

> 原文：`zh.javascript.info/1-js/05-data-types/05-array-methods/article.md`

## 知识点

### 1. splice：数组的瑞士军刀（删除/插入/替换）
`delete arr[1]` 只删值不删位置（留下空洞，length 不变），数组删除要用 `splice`。

```js
arr.splice(start[, deleteCount, elem1, ..., elemN])
```
- 从 `start` 开始，删除 `deleteCount` 个，再插入 `elem1...`；**返回被删除元素组成的数组**。

```js
let arr = ["I", "study", "JavaScript", "right", "now"];

arr.splice(1, 1);                 // 从索引 1 删 1 个 → ["I", "JavaScript", "right", "now"]
arr.splice(0, 3, "Let's", "dance"); // 删前 3 个换成 2 个 → ["Let's", "dance", "right", "now"]

let removed = arr.splice(0, 2);   // removed = ["Let's", "dance"]

arr.splice(2, 0, "complex", "language"); // deleteCount=0 → 纯插入
arr.splice(-1, 0, 3, 4);          // 支持负索引（从末尾数）
```

### 2. slice：复制子数组（不改原数组）
```js
arr.slice([start], [end])  // 复制 [start, end) 到新数组，支持负索引
["t","e","s","t"].slice(1, 3); // e,s
["t","e","s","t"].slice(-2);   // s,t
arr.slice()                // 完整副本（常用于"先复制再转换"保护原数组）
```

### 3. concat：合并成新数组
```js
let arr = [1, 2];
arr.concat([3, 4]);          // 1,2,3,4
arr.concat([3, 4], [5, 6]);  // 1,2,3,4,5,6
arr.concat([3, 4], 5, 6);    // 1,2,3,4,5,6（数组会展开，普通值原样加）
```
- 类数组对象默认被**整体当作一个元素**加入；除非它带 `Symbol.isConcatSpreadable: true` 才会被展开（了解即可）。

### 4. forEach：遍历
```js
arr.forEach(function(item, index, array) { ... });
["Bilbo", "Gandalf", "Nazgul"].forEach((item, index) => alert(`${item} at ${index}`));
```
- 返回值被忽略，**不能 break**（要中断用普通 for）。

### 5. 搜索
**indexOf / lastIndexOf / includes**：
- `arr.indexOf(item, from?)` → 索引或 -1；`lastIndexOf` 从右往左。
- `arr.includes(item, from?)` → true/false。
- 都用**严格相等 `===`** 比较（找 `false` 不会匹配 `0`）。
- 差异：`includes` 能正确找到 `NaN`，`indexOf` 不能：

```js
const arr = [NaN];
arr.indexOf(NaN);  // -1（因为 NaN !== NaN）
arr.includes(NaN); // true（includes 用了更新的比较算法）
```

**find / findIndex / findLastIndex**（对象数组常用）：
```js
let users = [{id:1, name:"John"}, {id:2, name:"Pete"}, {id:3, name:"Mary"}];
let user = users.find(item => item.id == 1);  // {id:1, name:"John"}
```
- 回调 `(item, index, array)` 返回 true 即停止并返回该元素；找不到返回 `undefined`。
- `findIndex` 返回索引（找不到 -1）；`findLastIndex` 从右往左找（ES2023）。

**filter**：要所有匹配项
```js
let someUsers = users.filter(item => item.id < 3); // 返回匹配元素的新数组，找不到是 []
```

### 6. map：变换
```js
let lengths = ["Bilbo", "Gandalf", "Nazgul"].map(item => item.length); // [5,7,6]
```
对每个元素调回调，把**返回值**收集成新数组。

### 7. sort(fn)：默认按字符串排序的大坑！
```js
let arr = [1, 2, 15];
arr.sort();
alert(arr); // 1, 15, 2 —— 元素被转成字符串按字典序排，"2" > "15"！
```
- **数字排序必须传比较函数**：

```js
arr.sort((a, b) => a - b); // 1, 2, 15（正数=大于，负数=小于）
```
- **sort 是原位（in-place）排序**，修改原数组；返回值也是原数组（通常忽略）。
- 字符串排序（含变音符号）用 `localeCompare`：

```js
let countries = ['Österreich', 'Andorra', 'Vietnam'];
countries.sort((a, b) => a.localeCompare(b)); // Andorra,Österreich,Vietnam ✓
```

### 8. reverse：原位反转
```js
[1,2,3,4,5].reverse(); // [5,4,3,2,1]
```

### 9. split 和 join：字符串 ↔ 数组
```js
let arr = 'Bilbo, Gandalf, Nazgul'.split(', '); // 按分隔符拆成数组
'test'.split('');      // ['t','e','s','t'] 拆成字母
'a,b,c,d'.split(',', 2); // 第二参数限制长度 → ['a','b']

let str = ['Bilbo','Gandalf','Nazgul'].join(';'); // "Bilbo;Gandalf;Nazgul"
```

### 10. reduce / reduceRight：折叠成单个值
```js
let value = arr.reduce(function(accumulator, item, index, array) { ... }, initial);
```
- `accumulator` 是上一次调用的结果，第一次等于 `initial`。

```js
let result = [1,2,3,4,5].reduce((sum, current) => sum + current, 0); // 15
```
- 省略 `initial` 时用第一个元素当初值、从第二个开始迭代；**但空数组会报错**（"Reduce of empty array with no initial value"）→ **建议始终给初始值**。
- `reduceRight` 从右往左。

### 11. Array.isArray
`typeof []` 是 `"object"`，无法区分数组和普通对象：

```js
Array.isArray([]); // true
Array.isArray({}); // false
```

### 12. thisArg（了解即可）
`find/filter/map` 等（`sort` 除外）可传最后一个参数 `thisArg`，作为回调里的 `this`：

```js
users.filter(army.canJoin, army);
// 更常见、更易懂的写法：users.filter(user => army.canJoin(user))
```

### 13. 其他方法速览
- `arr.some(fn)` / `arr.every(fn)`：任一/全部满足。行为像 `||`/`&&`（短路）。可用 `every` 逐项比较两数组。
- `arr.fill(value, start, end)`：填充。
- `arr.flat(depth)` / `arr.flatMap(fn)`：多维拍平。
- `Array.of(...)`：用参数建数组（避开 `new Array(2)` 的歧义）。

### ⚠️ 会修改原数组的方法
`sort`、`reverse`、`splice`（以及 push/pop/shift/unshift/fill/copyWithin）。其余如 `slice/concat/map/filter` 返回新数组。

## 方法备忘单（按用途分组）
| 用途 | 方法 |
|---|---|
| 增删 | `push/pop/shift/unshift/splice/slice/concat` |
| 搜索 | `indexOf/lastIndexOf/includes/find/findIndex/filter` |
| 遍历 | `forEach` |
| 变换 | `map/sort/reverse/split/join/reduce/reduceRight` |
| 其他 | `Array.isArray/some/every/fill/flat` |

## 与 Java 对比（Stream API）
| Java Stream / List | JS 数组方法 | 说明 |
|---|---|---|
| `stream.map(f).collect(toList())` | `arr.map(f)` | JS 直接返回新数组，不用 collect |
| `stream.filter(p)` | `arr.filter(p)` | 一致 |
| `stream.reduce(0, (a,b)->a+b)` | `arr.reduce((a,b)=>a+b, 0)` | 参数顺序相反：JS 是 (fn, initial) |
| `stream.findFirst()` → Optional | `arr.find(p)` → 元素或 undefined | JS 没有 Optional，返回 undefined |
| `stream.findAny`/`filter().findFirst()` | `arr.filter(p)` 拿全部 | — |
| `list.sort(Comparator.comparing(...))` | `arr.sort((a,b)=>a-b)` | 都改原数组；JS 默认按字符串排是大坑 |
| `list.subList(b,e)`（视图！） | `arr.slice(b,e)`（副本） | Java subList 是视图会联动，JS slice 是拷贝 |
| `list.addAll` | `arr.concat`（新数组）或 `push(...items)` | concat 返回新数组 |
| `list.contains(x)` | `arr.includes(x)` | ES6 |
| `Collections.reverse(list)` | `arr.reverse()` | 一致 |
| `String.join(";", list)` / `String.split` | `arr.join(';')` / `str.split(', ')` | 一致 |
| `stream.anyMatch/allMatch` | `arr.some/every` | 一致 |
| `list.remove(index)` | `arr.splice(index, 1)` | splice 可删可插可替换 |
| `flatMap` | `arr.flat()` / `arr.flatMap(fn)` | 一致 |

## 一句话总结
增删用 `splice`（万能）和 `slice`（复制）；搜索按值用 `includes/indexOf`，按条件用 `find/filter`；变换三板斧 `map/filter/reduce` 对应 Java Stream 同名概念；`sort` 默认按**字符串**排序，数字必须传 `(a,b)=>a-b`；`sort/reverse/splice` 改原数组，其余返回新数组；`reduce` 记得给初始值防空数组报错。

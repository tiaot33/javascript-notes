# 06 Iterable object（可迭代对象）

> 原文：`zh.javascript.info/1-js/05-data-types/06-iterable/article.md`
> ES6 核心概念，理解 `for..of` 背后的协议。

## 知识点

### 1. 什么是可迭代
- **可迭代（Iterable）** 是数组的泛化：任何对象只要实现了迭代协议，就能用于 `for..of`。
- 数组、字符串等很多内建对象都是可迭代的。

### 2. `Symbol.iterator` 协议（核心）
给对象加一个 `Symbol.iterator` 方法即可让它可迭代。协议流程：

1. `for..of` 启动时调用 `obj[Symbol.iterator]()`，它必须返回一个**迭代器（iterator）** —— 一个有 `next` 方法的对象。
2. 之后 `for..of` 只跟这个迭代器打交道。
3. 每次取下一个值就调用 `next()`。
4. `next()` 必须返回 `{done: Boolean, value: any}`：`done: true` 循环结束；否则 `value` 是当前值。

完整示例——让 `range` 对象可迭代：

```js
let range = { from: 1, to: 5 };

range[Symbol.iterator] = function() {
  return {
    current: this.from,
    last: this.to,
    next() {
      if (this.current <= this.last) {
        return { done: false, value: this.current++ };
      } else {
        return { done: true };
      }
    }
  };
};

for (let num of range) alert(num); // 1,2,3,4,5
```

**关注点分离**：`range` 自身没有 `next()`，迭代状态放在单独的迭代器对象里。

- 简化写法：让 `Symbol.iterator` 返回 `this`（对象自身当迭代器），代码更短，但**无法同时跑两个 `for..of`**（共享迭代状态）。
- 无穷迭代器也可以：`next` 永远返回值，用 `break` 停止。

### 3. 字符串是可迭代的，且能识别代理对
```js
for (let char of "test") alert(char); // t,e,s,t

let str = '𝒳😂';
for (let char of str) alert(char); // 𝒳，然后 😂 —— 代理对正确拆分！
```
对比：`str[0]`、`str.length` 会把代理对当两个码元，`for..of` 不会。

### 4. 显式调用迭代器
```js
let str = "Hello";
let iterator = str[Symbol.iterator]();  // 和 for..of 做的是同一件事

while (true) {
  let result = iterator.next();
  if (result.done) break;
  alert(result.value);
}
```
很少需要手写，但比 `for..of` 控制力强：可以迭代一半停下来做别的，再恢复。

### 5. 可迭代 vs 类数组（array-like）—— 两个易混概念
| 概念 | 定义 | 例子 |
|---|---|---|
| **Iterable** | 实现了 `Symbol.iterator` | 数组、字符串、`range` |
| **Array-like** | 有索引和 `length` 属性 | `{0:"Hello", 1:"World", length:2}` |

- 字符串两者都是；`range` 可迭代但不是类数组（无索引无 length）；上面的 `arrayLike` 是类数组但不可迭代（`for..of` 报错）。
- 它们通常**都不是真数组**，没有 `push/pop` 等方法。

### 6. `Array.from`：可迭代/类数组 → 真数组（ES6）
```js
let arrayLike = { 0: "Hello", 1: "World", length: 2 };
let arr = Array.from(arrayLike);
arr.pop(); // 现在可以用数组方法了
```

完整语法带映射函数：
```js
Array.from(obj[, mapFn, thisArg])

let arr = Array.from(range, num => num * num); // 1,4,9,16,25
```

处理代理对字符串的正确姿势：
```js
let str = '𝒳😂';
let chars = Array.from(str);  // 依赖可迭代性，代理对正确
chars.length; // 2（而 str.length 是 4）

// 代理对感知的 slice：
function slice(str, start, end) {
  return Array.from(str).slice(start, end).join('');
}
slice('𝒳😂𩷶', 1, 3); // 😂𩷶（原生 str.slice 会得到乱码）
```

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `Iterable<T>` 接口，方法 `iterator()` | `Symbol.iterator` 方法 | 协议思想一样，JS 用 Symbol 作方法名避免命名冲突 |
| `Iterator<T>`：`hasNext()` + `next()` | 迭代器的 `next()` 返回 `{done, value}` | JS 把两个方法合并成一个，done 替代 hasNext |
| 增强 for（for-each） | `for..of` | 语法糖对应的协议一致 |
| `Collection` 等内建可迭代 | 数组、字符串、Map、Set 内建可迭代 | JS 字符串也可迭代（Java 的 String 不能 for-each） |
| `Arrays.asList(...)` / 集合转换 | `Array.from(iterable)` | JS 一招通吃可迭代和类数组 |
| 无对应概念 | 类数组对象（有索引+length） | JS 特有，DOM 的 NodeList、`arguments` 都是类数组 |
| `stream().map().collect()` | `Array.from(obj, mapFn)` | 转换+映射一步完成 |

## 一句话总结
可迭代 = 实现了 `Symbol.iterator` 方法的对象，它返回带 `next()` 的迭代器，`next()` 每次给出 `{done, value}`；`for..of` 只是这个协议的语法糖；字符串可迭代且能正确处理代理对；"可迭代"（有 Symbol.iterator）和"类数组"（有索引+length）是两回事；`Array.from` 可以把任何一种转换成真数组。

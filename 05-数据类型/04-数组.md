# 04 数组

> 原文：`zh.javascript.info/1-js/05-data-types/04-array/article.md`

## 知识点

### 1. 声明与基本操作
```js
let arr = new Array(); // 几乎不用
let arr = [];          // 主流写法
let fruits = ["Apple", "Orange", "Plum"];

fruits[0];        // Apple（从 0 开始）
fruits[2] = 'Pear';   // 替换
fruits[3] = 'Lemon';  // 直接扩容添加
fruits.length;    // 4
```
- 数组**可存储任意类型混合**：`[ 'Apple', {name:'John'}, true, function(){...} ]`。
- 建议尾随逗号，方便增删行。
- ⚠️ 数组是**动态长度**的，不像 Java 数组定长。

### 2. `at(-1)` 取最后一个元素（ES2022）
```js
fruits[fruits.length - 1]; // Plum，传统写法
fruits.at(-1);             // Plum，新语法
```
- `arr.at(i)`：`i >= 0` 时同 `arr[i]`；负数从尾部倒数。
- ⚠️ `fruits[-1]` **不行**，得到 `undefined`（方括号索引按字面处理）。

### 3. push/pop/shift/unshift：双端队列
数组既可当栈也可当队列（deque）：

| 方法 | 端 | 动作 |
|---|---|---|
| `push(...items)` | 尾 | 添加（可多个） |
| `pop()` | 尾 | 取出并返回 |
| `unshift(...items)` | 首 | 添加（可多个） |
| `shift()` | 首 | 取出并返回 |

- 栈（LIFO）= push + pop；队列（FIFO）= push + shift。
- `fruits.pop()` vs `fruits.at(-1)`：都返回末尾元素，但 `pop` 会**删除**它。

**性能差异**（重要）：
- `push/pop` 快：只动末尾，其他元素索引不变。
- `shift/unshift` 慢：所有元素要**重新编号**（移动内存），元素越多越慢。

### 4. 数组的本质：特殊的对象
- `arr[0]` 本质就是对象语法 `obj[key]`，数字作键。
- **按引用复制**：

```js
let fruits = ["Banana"];
let arr = fruits;
arr === fruits;  // true
arr.push("Pear");
alert(fruits);   // Banana,Pear（同一个数组）
```

- 引擎对"连续有序数据"做优化，**误用会关闭优化**：
  - 加非数字属性 `arr.test = 5`
  - 制造空洞 `arr[0]` 然后 `arr[1000]`
  - 倒序填充 `arr[1000], arr[999]...`
- 需要任意键值时请用普通对象 `{}`。

### 5. 遍历方式
```js
for (let i = 0; i < arr.length; i++) { ... } // 最老，最快，兼容旧浏览器

for (let item of arr) { ... }  // 现代语法（ES6），拿不到索引但够用

for (let key in arr) { ... }   // ❌ 永远别用！
```
`for..in` 的问题：
1. 遍历**所有属性**（包括类数组对象上的非数字属性）。
2. 为普通对象优化，用在数组上慢 10~100 倍。

### 6. `length` 的真相
- `length` 不是元素个数，而是**最大数字索引 + 1**：

```js
let fruits = [];
fruits[123] = "Apple";
alert( fruits.length ); // 124
```

- `length` **可写**：缩小会**截断数组（不可逆）**，增大无效果：

```js
let arr = [1, 2, 3, 4, 5];
arr.length = 2;  // 截断为 [1, 2]
arr.length = 5;  // 恢复长度，但元素没了
alert( arr[3] ); // undefined
```
- **清空数组最简单的方法：`arr.length = 0;`**

### 7. `new Array()` 的坑
```js
let arr = new Array(2); // 是 [2] 吗？不！
alert( arr[0] );        // undefined
alert( arr.length );    // 2 —— 单个数字参数表示长度！
```
单数字参数创建的是**指定长度的空数组**。避免歧义，用 `[]`。

### 8. 多维数组
```js
let matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];
alert( matrix[1][1] ); // 5
```

### 9. `toString`：逗号连接
```js
alert( [1, 2, 3] ); // "1,2,3"
alert( [] + 1 );    // "1"   —— [] → ""
alert( [1] + 1 );   // "11"  —— [1] → "1"
alert( [1,2] + 1 ); // "1,21"
```
数组没有 `Symbol.toPrimitive` 和 `valueOf`，转原始值只能走 `toString`。

### 10. 不要用 `==` 比较数组
- `==` 对数组按普通对象处理：**只有引用同一个数组才相等**：

```js
alert( [] == [] );   // false
alert( [0] == [0] ); // false
```

- 与原始类型比较时会先把数组转成字符串，结果很怪：

```js
alert( 0 == [] );   // true（[] → '' → 0）
alert( '0' == [] ); // false（[] → ''，'0' ≠ ''）
```

- 正确做法：循环或迭代方法逐项比较（下一章的方法）。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| 数组定长，`ArrayList` 动态 | 数组天然动态扩容 | JS 数组 ≈ Java 的 `ArrayList<Object>`（还允许混合类型） |
| `list.get(i)` / `list.set(i, v)` | `arr[i]` | 越界 Java 抛异常，JS 返回 undefined / 静默扩容 |
| `list.get(list.size()-1)` | `arr.at(-1)` 或 `arr[arr.length-1]` | `arr[-1]` 是 undefined 不是最后元素 |
| `ArrayDeque` 的 push/pop/offer/poll | push/pop/shift/unshift | shift/unshift 因为要重编号是 O(n)，尽量少用 |
| `list.size()` | `arr.length`（属性） | 又是属性不是方法；且是"最大索引+1" |
| 数组 == 也是引用比较 | 相同 | 内容比较 Java 用 `Arrays.equals` / `list.equals`，JS 只能手动逐项比 |
| 增强 for 循环 | `for..of` | 一致；但 JS 千万别对数组用 `for..in` |
| `Arrays.toString(arr)` | `arr.toString()` | JS 直接逗号连接无括号 |
| `new int[2]` 是长度为 2 的空数组 | `new Array(2)` 也是 | 但 JS 里 `new Array("2")` 又是 ["2"]，歧义大，用字面量 |

## 一句话总结
数组是动态长度的有序集合（本质是特殊对象，按引用复制）；`push/pop` 快、`shift/unshift` 慢；遍历用普通 `for` 或 `for..of`，**禁用 `for..in`**；`length` 是最大索引+1 且可写（`arr.length = 0` 即清空）；取末尾用 `at(-1)`；`new Array(2)` 是长度 2 的空数组不是 `[2]`；数组不能用 `==` 比较内容。

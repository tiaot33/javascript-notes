# 02 数字类型

> 原文：`zh.javascript.info/1-js/05-data-types/02-number/article.md`

## 知识点

### 0. 两种数字
- **常规数字**：64 位 IEEE-754 双精度浮点数（就是 Java 的 `double`），日常全用它。安全整数范围 `±(2^53 - 1)`。
- **BigInt**：任意长度整数，特殊领域才用，单独章节讲。
- ⚠️ JS **没有 int/long/float 之分**，所有普通数字都是 double。

### 1. 数字字面量的写法
```js
let billion = 1_000_000_000; // 下划线分隔符（ES2021），引擎直接忽略
let billion2 = 1e9;          // e9 = 后面 9 个 0
1e-3 === 1 / 1000;           // e-3 = 除以 1000

alert( 0xff );        // 255 十六进制
alert( 0b11111111 );  // 255 二进制
alert( 0o377 );       // 255 八进制
```
只有这三种进制有字面量前缀，其他进制用 `parseInt`。

### 2. `num.toString(base)`：转任意进制字符串
```js
let num = 255;
alert( num.toString(16) ); // ff
alert( num.toString(2) );  // 11111111
```
- `base` 范围 2~36，默认 10。
- **base=36 妙用**：把长数字 ID 压缩成短字符串（短 URL）：`123456..toString(36)` → `"2n9c"`。
- ⚠️ **两个点的坑**：直接在数字字面量上调方法要写 `123456..toString(36)`（第一个点被当作小数点），或 `(123456).toString(36)`。

### 3. 舍入
| 输入 | `Math.floor` | `Math.ceil` | `Math.round` | `Math.trunc` |
|---|---|---|---|---|
| `3.1` | 3 | 4 | 3 | 3 |
| `3.6` | 3 | 4 | 4 | 3 |
| `-1.1` | **-2** | -1 | -1 | -1 |
| `-1.6` | -2 | -1 | **-2** | -1 |

- `Math.trunc`：直接砍掉小数部分（IE 不支持）。
- 舍入到小数点后 n 位，两种方法：
  1. 乘除法：`Math.round(num * 100) / 100`（返回数字）。
  2. `num.toFixed(n)`：类似 `Math.round`，但**返回字符串**，不足补零：

```js
alert( 12.34.toFixed(1) ); // "12.3"
alert( 12.36.toFixed(1) ); // "12.4"
alert( 12.34.toFixed(5) ); // "12.34000"
+num.toFixed(2);           // 一元加号转回数字
```

### 4. 不精确的计算（重点）
```js
alert( 0.1 + 0.2 == 0.3 ); // false!
alert( 0.1 + 0.2 );        // 0.30000000000000004
```
- 原因：`0.1`、`0.2` 在二进制中是**无限循环小数**（如同 1/3 在十进制中），IEEE-754 只能存近似值，误差会叠加。
- 这不是 JS 独有的问题——**Java/PHP/C 用 double 结果完全一样**。
- 应对：
  - 显示时用 `toFixed(n)` 剪掉尾巴：`(0.1+0.2).toFixed(2)` → `"0.30"`。
  - 先乘成整数再算可以**减少**误差但不能消除：`(0.1*10 + 0.2*10)/10` = 0.3，但 `(0.28*100 + 0.14*100)/100` = 0.4200000000000001。
  - 实战建议：金额用"分"存储；必要时再 toFixed。
- 其他冷知识：
  - 数字太大溢出 → `Infinity`：`1e500` → Infinity。
  - `9999999999999999` → `10000000000000000`（超过 52 位尾数，精度丢失，静默不报错）。
  - 存在 `0` 和 `-0` 两个零，运算符把它们视为相等。

### 5. 检测：`isNaN` 和 `isFinite`
- `NaN` 不等于任何东西，**包括它自己**：

```js
alert( NaN === NaN ); // false，所以不能用 === 判断
alert( isNaN(NaN) );  // true
alert( isNaN("str") ); // true（先转数字，"str"→NaN）
```

- `isFinite(value)`：转成数字后，是常规数字（非 `NaN/±Infinity`）才返回 true，常用来校验输入：

```js
alert( isFinite("15") );      // true
alert( isFinite("str") );     // false
alert( isFinite(Infinity) );  // false
```
- ⚠️ 所有数字函数里，**空字符串或纯空格字符串按 0 处理**。
- `Object.is(a, b)`：类似 `===`，但两个边缘情况更可靠：
  - `Object.is(NaN, NaN)` → `true`
  - `Object.is(0, -0)` → `false`
  其余情况与 `===` 相同，规范内部比较用的就是它（SameValue）。

### 6. `parseInt` / `parseFloat`：从带单位的字符串"读"数字
- `+` 和 `Number()` 是**严格转换**：`+"100px"` → `NaN`（整体不像数字就失败）。
- `parseInt/parseFloat` 是**软转换**：从头读数字，读不动为止：

```js
alert( parseInt('100px') );     // 100
alert( parseFloat('12.5em') );  // 12.5
alert( parseInt('12.3') );      // 12（只取整数部分）
alert( parseFloat('12.3.4') );  // 12.3（第二个点停止）
alert( parseInt('a123') );      // NaN（第一个字符就读不动）
```

- `parseInt(str, radix)` 第二参数指定进制：

```js
alert( parseInt('0xff', 16) ); // 255
alert( parseInt('ff', 16) );   // 255，没有 0x 也行
alert( parseInt('2n9c', 36) ); // 123456
```

### 7. `Math` 对象
- `Math.random()` —— `[0, 1)` 随机数。
- `Math.max(a, b, c...)` / `Math.min(...)` —— 任意多个参数。
- `Math.pow(n, power)` —— 幂（现代写法更常用 `n ** power`）。
- 更多三角函数、常量见 MDN。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `int`、`long`、`double` 等多种类型 | 只有 `number`（double）+ `BigInt` | JS 整数也是浮点，安全整数 ±2^53-1 |
| `double` 的 0.1+0.2 问题相同 | 相同 | 都是 IEEE-754，Java 人用 `BigDecimal`，JS 没有内置精确小数，常用"分"存金额 |
| `Integer.toString(255, 16)` | `(255).toString(16)` | JS 数字字面量直接调方法要写两个点 |
| `Math.floor/ceil/round` | 相同 | 注意负数行为：`Math.floor(-1.1)` 得 -2 |
| `(int) 3.9` 截断 | `Math.trunc(3.9)` | JS 的 `\|` 位运算也能截断但只限 32 位 |
| `Double.parseDouble("12.5em")` 抛异常 | `parseFloat('12.5em')` → 12.5 | JS 的 parse 系列是"尽力读取"，失败给 NaN 不抛异常 |
| `Double.isNaN(v)` / `Double.isFinite(v)` | `isNaN(v)` / `isFinite(v)` | JS 版会先隐式转数字，`isNaN("str")` 为 true |
| `NaN != NaN` 为 true | `NaN === NaN` 为 false | 一致 |
| `String.format("%.2f", x)` | `x.toFixed(2)` | toFixed 返回字符串 |
| `1_000_000` 数字分隔符（Java 7+） | `1_000_000` | 一致 |

## 一句话总结
JS 只有一种普通数字（IEEE-754 double），写法支持 `1e9`、`_` 分隔、`0x/0b/0o` 前缀；`toString(base)` 转进制、`toFixed(n)` 舍入成字符串；`0.1+0.2≠0.3` 是浮点通病，金额用分存储；`NaN` 连自己都不等于，判断用 `isNaN/isFinite`；带单位的字符串用 `parseInt/parseFloat` 软解析，严格转换用 `Number()`。

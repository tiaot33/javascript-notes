# 03 字符串

> 原文：`zh.javascript.info/1-js/05-data-types/03-string/article.md`

## 知识点

### 0. 基本事实
- 内部编码永远是 **UTF-16**，与页面编码无关。
- **没有单独的 char 类型**，单个字符也是字符串。
- 字符串**不可变**（与 Java 的 String 一样），改字符只能创建新字符串。

### 1. 三种引号
```js
let single = 'single';
let double = "double";
let backticks = `backticks`;
```
- 单/双引号基本相同，**不能跨行**。
- **反引号（ES6 模板字符串）**：
  - `${…}` 内嵌任意表达式：`` `1 + 2 = ${sum(1, 2)}.` ``
  - 可以**跨行书写**，换行就是字符串的一部分。
- 进阶：反引号前可以放"模版函数" `` func`string` ``（tagged templates），很少用，了解即可。

### 2. 特殊字符
- `\n` 换行、`\r`、`\t`、`\'`、`\"`、`\\`。
- `\xXX`：两位十六进制 Unicode。
- `\uXXXX`：UTF-16 编码（必须正好 4 位十六进制）。
- `\u{X…XXXXXX}`：1~6 位十六进制的长代码（emoji、罕见汉字用）。

```js
alert( "\u00A9" );      // ©
alert( "\u{1F60D}" );   // 😍
```
- 反斜杠只用于"读取时转义"，内存中的字符串没有 `\`；要显示真正的 `\` 就写 `\\`。

### 3. 长度：`str.length` 是**属性**不是方法
```js
alert( `My\n`.length ); // 3（\n 是一个字符）
```
⚠️ Java 程序员的经典错误：`str.length()` —— 会报错，别加括号。

### 4. 访问字符
```js
let str = `Hello`;
str[0];               // H，现代写法
str.charAt(0);        // H，历史遗留
str[str.length - 1];  // o，最后一个

str[1000];            // undefined（不报错！）
str.charAt(1000);     // ''（空字符串）
```
- 越界时 `[]` 返回 `undefined`，`charAt` 返回空串——这是两者唯一区别。
- `for..of` 遍历字符：`for (let char of "Hello")`，且能正确处理代理对（emoji）。

### 5. 不可变性
```js
let str = 'Hi';
str[0] = 'h';  // 静默失败（严格模式报错），str 不变
str = 'h' + str[1]; // 只能创建新字符串赋值
```

### 6. 大小写
```js
'Interface'.toUpperCase(); // INTERFACE
'Interface'[0].toLowerCase(); // 'i'
```

### 7. 查找子字符串
- `str.indexOf(substr, pos?)`：从 pos 起找，返回位置或 `-1`；`str.lastIndexOf` 反向。
- ⚠️ **经典坑**：`if (str.indexOf("Widget"))` —— 找到在位置 0 时 `0` 是 falsy，判断失败！必须写 `!= -1`。
- 老代码里的位非技巧：`~n === -(n+1)`，只有 `n == -1` 时 `~n` 为 0，所以 `if (~str.indexOf(...))` 读作 "if found"。现代代码用 `includes`，看懂即可。
- **现代方法（ES6）**：

```js
"Widget with id".includes("Widget");    // true
"Widget".includes("id", 3);             // false（从位置 3 开始没有）
"Widget".startsWith("Wid");             // true
"Widget".endsWith("get");               // true
```
只需判断是否包含时用 `includes`，不需要位置。

### 8. 截取子字符串：三个方法对比
| 方法 | 语义 | 负值参数 |
|---|---|---|
| `slice(start, end)` | 从 start 到 end（**不含** end） | 允许（从末尾数） |
| `substring(start, end)` | 同上，但 **start > end 也可以**（自动交换） | 负值当作 0 |
| `substr(start, length)` | 从 start 取 length 个 | start 允许负值 |

```js
let str = "stringify";
str.slice(0, 5);   // 'strin'
str.slice(2);      // 'ringify'（省略 end 到末尾）
str.slice(-4, -1); // 'gif'

str.substring(2, 6); // "ring"
str.substring(6, 2); // "ring"（参数互换，一样）
str.slice(6, 2);     // ""（slice 不允许 start > end）

str.substr(2, 4);    // 'ring'
```
- **结论：只记 `slice` 就够了**。`substr` 不在核心规范而在附录 B（历史遗留），尽量避免。

### 9. 字符串比较
- 默认按 **UTF-16 码元数值**逐字符比较，所以有怪事：

```js
alert( 'a' > 'Z' );                  // true（小写码 97 > 大写码 90）
alert( 'Österreich' > 'Zealand' );   // true（Ö 码很大）
```

- `str.codePointAt(pos)` 取字符码；`String.fromCodePoint(code)` 由码建字符。
- **正确的多语言比较**：`str.localeCompare(str2)`（ECMA-402）
  - str 排前 → 负数；排后 → 正数；相同 → 0。

```js
alert( 'Österreich'.localeCompare('Zealand') ); // -1（符合字典序）
```

### 10. Unicode 深入（代理对与规范化）
- UTF-16 两字节只有 65536 个组合，不够用；**罕见字符用"代理对"（两个 2 字节码元）编码**。
- 后果：这些字符的 `length` 是 **2**：

```js
alert( '😂'.length ); // 2
'𝒳'[0]; // 半个代理对，乱码
```

- `codePointAt/fromCodePoint` 能处理代理对；老的 `charCodeAt/fromCharCode` 不能。
- 代理对检测：第一码元在 `0xd800..0xdbff`，第二码元在 `0xdc00..0xdfff`。
- **变音符号与规范化**：视觉上相同的字符可能有不同的码元组合（`S + 上点 + 下点` 两种顺序），`==` 为 false。用 `str.normalize()` 归一后再比较：

```js
"S\u0307\u0323".normalize() == "S\u0323\u0307".normalize(); // true
```

### 11. 其他常用方法（原文总结提到）
- `str.trim()` —— 去掉首尾空白。
- `str.repeat(n)` —— 重复 n 次。
- 正则相关方法在正则表达式章节。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `char` 类型存在 | 没有 char，都是 string | JS 单字符也是字符串 |
| `String` 不可变 | 不可变 | 一致 |
| `s.length()` | `s.length`（属性！） | 经典踩坑点 |
| `s.charAt(i)` | `s[i]` 或 `s.charAt(i)` | `[]` 越界得 undefined，charAt 越界得 "" |
| `s.indexOf("x")` | `s.indexOf("x")` | 一致，都返回 -1；但 JS 里 `if (indexOf(...))` 是坑（0 为 falsy） |
| `s.contains("x")` | `s.includes("x")` | ES6 新增 |
| `s.startsWith/endsWith` | 同名 | 一致 |
| `s.substring(b, e)` | `s.slice(b, e)` | JS 的 slice 支持负索引（从末尾数），更灵活；Java substring 越界抛异常，JS slice 宽容 |
| `s.toUpperCase()/toLowerCase()` | 同名 | 一致 |
| `s.trim()` | `s.trim()` | 一致 |
| `String.format` / 文本块（Java 15+） | 模板字符串 `` `${expr}` `` | JS 反引号内嵌表达式 + 天然多行，比 Java 文本块更灵活 |
| `compareTo` 按 Unicode 码点比较 | 默认比较也按 UTF-16 码元 | 一致；多语言排序 Java 用 `Collator`，JS 用 `localeCompare` |
| Java 字符串也是 UTF-16 | 相同 | `😂.length()` 在 Java 里也是 2，代理对问题一样 |
| `s.repeat(n)`（Java 11+） | `s.repeat(n)` | 一致 |

## 一句话总结
字符串是 UTF-16 编码、不可变的；反引号模板字符串支持 `${表达式}` 和多行，是现代主流写法；`length` 是属性；查用 `includes/indexOf`（小心 `if(indexOf)` 的 0 坑），截取只记 `slice`（支持负索引），比较注意按码元排序、多语言用 `localeCompare`；emoji 等代理对字符 length 为 2，遍历用 `for..of` 才能正确拆分。

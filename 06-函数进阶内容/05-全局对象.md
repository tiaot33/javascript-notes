# 05 全局对象

> 原文：`zh.javascript.info/1-js/06-advanced-functions/05-global-object/article.md`
> 篇幅很短，记住 `globalThis` 和 `var` 的特殊行为即可。

## 知识点

### 1. 什么是全局对象
- 提供在任何地方都可用的变量和函数（内建于语言或运行环境）。
- 不同环境的名字不同：浏览器 `window`、Node.js `global`。
- **`globalThis` 是 ES2020 加入的标准名称**，所有环境都支持，写跨环境代码用它。

### 2. 全局对象的属性可直接访问
```js
alert("Hello");
// 等同于（浏览器中）
window.alert("Hello");
```

### 3. `var` 全局声明会挂到全局对象上（浏览器、非模块环境下）
```js
var gVar = 5;
alert(window.gVar); // 5 —— 成了全局对象的属性

let gLet = 5;
alert(window.gLet); // undefined —— let/const 不会
```
- 主代码流中的**函数声明**也有同样效果（函数表达式没有）。
- 这是为了兼容性保留的行为，**不要依赖它**；现代代码用 ES 模块，模块里不会发生。

### 4. 显式使用全局对象
确实需要全局共享的值，直接写成全局对象的属性，**显式**访问更安全：

```js
window.currentUser = { name: "John" };
alert(window.currentUser.name); // 显式写法能避开同名局部变量的遮蔽
```
- 原则：全局变量越少越好；函数"输入 → 输出"的设计更清晰、易测试。

### 5. 用途：特性检测与 polyfill
```js
if (!window.Promise) {
  window.Promise = ...; // 为旧浏览器补上现代功能的实现（polyfill）
}
```

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| 无"全局对象"；最接近的是 `System` 类的静态成员 | `window` / `global` / `globalThis` | JS 顶层作用域就是一个可增删属性的对象 |
| `public static` 字段全局共享 | 全局变量（或 `window.x`） | 都该少用，JS 里更容易不小心创建全局变量 |
| 无 polyfill 概念（用 classpath 多版本 jar 或条件实现） | 检测全局对象属性 → 补 polyfill | 前端特有模式：`if (!window.Promise) { ... }` |
| —— | `globalThis` 统一入口 | 类似 Java 里写一个屏蔽 OS 差异的工具类 |

## 一句话总结
全局对象是环境提供的顶层可访问对象（浏览器 `window`、Node `global`，标准名 **`globalThis`**）；浏览器非模块环境中 `var` 和函数声明的全局量会成为它的属性（`let/const` 不会），跨环境代码用 `globalThis`，全局变量保持最少，它最常见的正面用途是特性检测 + polyfill。

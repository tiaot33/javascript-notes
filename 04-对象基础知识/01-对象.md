# 01 对象

> 原文：`zh.javascript.info/1-js/04-object-basics/01-object/article.md`

## 知识点

### 0. 对象是什么
- 对象是**键值对（key: value）集合**：键是字符串（或 symbol，后续讲），值可以是任意类型。
- 可以把它理解成一个"自带点访问语法的 HashMap"。

### 1. 创建对象
```js
let user = new Object(); // “构造函数”语法，几乎不用
let user = {};           // “字面量”语法，主流写法
```

### 2. 属性的增删改查
```js
let user = { name: "John", age: 30 }; // 字面量直接带属性

user.isAdmin = true;   // 随时添加属性（对象结构是动态的）
delete user.age;       // delete 操作符删除属性
```
- 多词属性名必须加引号：`{ "likes birds": true }`。
- 建议每个属性后都加**尾随逗号**，方便增删移动。

### 3. 点符号 vs 方括号
- **点符号**：`obj.prop`，要求键是合法标识符（无空格、不以数字开头）。
- **方括号**：`obj["prop"]`，接受**任意字符串和表达式**，包括变量：

```js
let key = "name";
alert(user[key]);  // 动态键，点符号做不到（user.key 是找字面键 "key"）
```

- 对象字面量里的**计算属性（Computed Properties）**（ES6）：
  - 当属性名需要**动态从变量或表达式获取**时，必须在键名外加 `[ ]`。
  - **核心对比**：
    - `{ fruit: 5 }` → 键名固定死是字符串 `"fruit"`
    - `{ [fruit]: 5 }` → 读取变量 `fruit` 的值（`"apple"`）作为键名，得到 `{ apple: 5 }`

```js
let fruit = "apple";

// 1. 变量作为键名
let bag = {
  [fruit]: 5 // 实际为 { apple: 5 }，等同于 bag = {}; bag[fruit] = 5
};

// 2. 表达式作为键名
let bag2 = {
  [fruit + "Computers"]: 5 // 实际为 { appleComputers: 5 }
};
```

### 4. 属性值简写（ES6）
属性名与变量名相同时可省略 `: value`：

```js
function makeUser(name, age) {
  return { name, age }; // 与 { name: name, age: age } 相同
}
```
简写和普通写法可混用。

### 5. 属性名的规则
- **没有保留字限制**：`{ for: 1, let: 2, return: 3 }` 合法。
- 键只能是字符串或 symbol；**其他类型自动转字符串**：`obj[0]` 和 `obj["0"]` 是同一个属性。
- 陷阱：`__proto__` 不能被赋值为非对象值（`obj.__proto__ = 5` 会被静默忽略），细节在原型章节讲。

### 6. 读取不存在的属性 → `undefined`，不报错
```js
let user = {};
alert(user.noSuchProperty === undefined); // true
```
- 属性存在性检查用 **`in` 运算符**：`"age" in user` → true/false。
- `in` 左侧是属性名字符串；省略引号则表示"取该变量的值作为键"。
- 为什么需要 `in`？因为属性**存在但值为 `undefined`** 时，比较法失效：

```js
let obj = { test: undefined };
obj.test;          // undefined，看起来像不存在
"test" in obj;     // true，其实存在
```

### 7. `for..in` 遍历
```js
for (let key in user) {
  alert(key);        // 键
  alert(user[key]);  // 值（注意要用方括号）
}
```
**属性顺序规则**（重要）：
- **整数属性**（能和整数无损互转的字符串键，如 `"49"`）按**数值升序**排列。
- 其他属性按**创建顺序**排列。
- `"49"` 是整数属性；`"+49"`、`"1.2"` 不是。

```js
let codes = { "49": "Germany", "41": "Switzerland", "1": "USA" };
for (let code in codes) alert(code); // 1, 41, 49 —— 整数键被排序了！
```
- 想保住插入顺序？给键加个前缀让它变非整数：`"+49"`。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `HashMap<String, Object>` | 普通对象 `{}` | JS 对象 ≈ Map + 点语法糖 |
| 字段在类中先声明，结构固定 | 属性随时增删，结构动态 | 同一变量指向的对象可以随时多出/少掉属性 |
| `map.get("name")` / `map.put(...)` | `obj.name` / `obj["name"]` | 键是变量时访问用 `obj[key]`，字面量动态键需用 `{[key]: val}` |
| `map.get` 不存在返回 `null` | 返回 `undefined`，不报错 | 不抛 NPE，容易藏 bug |
| `map.containsKey("k")` | `"k" in obj` | `in` 能区分"不存在"和"值为 undefined" |
| `LinkedHashMap` 保插入序 | 整数键升序，其余按插入序 | 整数键排序是个坑，用 `"+1"` 之类的键绕过 |
| `new HashMap<>()` | `{}`（字面量） | `new Object()` 几乎没人用 |

## 一句话总结
JS 对象就是"键值对集合 + 点语法"：键是字符串/symbol（其他类型自动转字符串），属性可动态增删；读不存在的属性得 `undefined` 不报错；遍历用 `for..in`，注意整数键会被自动排序。

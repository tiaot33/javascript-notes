# 03 柯里化（Currying）

> 原文：`zh.javascript.info/1-js/99-js-misc/03-currying-partials/article.md`
> 高阶函数技术：把 `f(a, b, c)` 变成 `f(a)(b)(c)`，核心价值是**方便地生成部分应用函数（partial）**。

## 知识点

### 1. 定义与最简实现
柯里化是一种**函数转换**（不调用函数，只改变调用形式）：`f(a, b, c)` → `f(a)(b)(c)`。

两参数版实现一目了然：
```js
function curry(f) {
  return function(a) {     // 包装器1：存住 a（闭包）
    return function(b) {   // 包装器2：存住 b
      return f(a, b);      // 参数齐了，调用原函数
    };
  };
}
let curriedSum = curry((a, b) => a + b);
curriedSum(1)(2); // 3
```
原理就是闭包：每次调用把参数存进词法环境，返回下一层包装器。

### 2. 实际中的柯里化（lodash `_.curry`）
真实库的实现更灵活——**正常调用和逐个传参都行**：
```js
let curriedSum = _.curry(sum);
curriedSum(1, 2);   // 3，正常调用
curriedSum(1)(2);   // 3，柯里化调用
```

### 3. 为什么要柯里化：逐步固定参数
日志函数 `log(date, importance, message)` 柯里化后：

```js
log = _.curry(log);
log(new Date(), "DEBUG", "some debug"); // 正常用
log(new Date())("DEBUG")("some debug"); // 柯里化用

let logNow = log(new Date());        // 固定第 1 个参数 → 部分应用函数
let debugNow = logNow("DEBUG");      // 再固定第 2 个 → 更专用的函数
debugNow("message");                 // [HH:mm] DEBUG message
```
收益：
1. 柯里化后**原功能不丢**，仍可一次性传全参；
2. 能逐级"预置"参数，派生出 `logNow`、`debugNow` 这类便捷函数——这就是**部分应用（partial application）**，柯里化是获得它的捷径。

### 4. 手写高级版 curry（支持任意传参组合）
```js
function curry(func) {
  return function curried(...args) {
    if (args.length >= func.length) {   // 参数够了（func.length = 声明的形参个数）
      return func.apply(this, args);    // 真正执行
    } else {
      return function(...args2) {       // 不够：返回新包装器
        return curried.apply(this, args.concat(args2)); // 合并新旧参数再判一次
      };
    }
  };
}

curriedSum(1, 2, 3); // 6
curriedSum(1)(2, 3); // 6
curriedSum(1)(2)(3); // 6
```
递归思路：每次调用判断"累计参数数 ≥ 形参数？"，够了就执行，不够就再包一层等下一批。

### 5. 限制
- **只适用参数个数固定的函数**：判断依据是 `func.length`，用 rest 参数（`f(...args)`）或带可选参数的函数无法这样柯里化。
- 纯定义上的柯里化是"一次只传一个参"，JS 实现多是"柯里化 + 部分应用"的混合体。

## 与 Java 对比
| Java | JS | 说明 |
|---|---|---|
| `Function<A, Function<B, R>>`（手写嵌套泛型，很别扭） | `curried(a)(b)` | JS 函数是一等公民，柯里化很自然 |
| Vavr：`Function3.curried()` | lodash `_.curry` | 都靠库提供通用实现 |
| 方法引用预绑定：`x -> log(now, x)` | `log(new Date())` 部分应用 | 目的相同：固定部分参数得到更简单的函数 |
| Stream/Builder 链式分步配置 | 逐级传参 `log(date)("DEBUG")` | 逐步细化行为的思路相通 |

## 一句话总结
柯里化 = 把 `f(a,b,c)` 转换为 `f(a)(b)(c)` 的纯转换（不执行函数）；靠闭包逐层存参数，参数凑够（`args.length >= func.length`）才真正调用原函数；实际库（lodash `_.curry`）支持正常调用与部分调用混用，其最大价值是逐级固定参数派生出 `logNow`、`debugNow` 这类部分应用函数；注意只适用于形参个数固定的函数。
